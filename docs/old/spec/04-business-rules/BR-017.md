---

## Rule

- **Statement:** The rule sets the **theme values every design system has**, and the **kinds of brand file** a design system holds.
- **Status:** confirmed
- **Why:** A design system holds **theme values**, **rules in words**, and the **logo and fonts of the brand**.

## Values

### V-1 · Theme values

- **Value:** **Closed list of named roles**:
  - **Colours:** `color.background`, `color.surface`, `color.text`, `color.muted`, `color.accent`, `color.onAccent`, `color.border`.
  - **Font families:** `font.heading`, `font.body`.
  - **Font sizes:** `type.display`, `type.heading`, `type.body`, `type.caption`.
  - **Spacing unit:** `space.unit`.
  - **Line height:** `type.lineHeight`.

### V-2 · Kinds of brand file

- **Value:** **Closed list**: logo, font file.

## Notes

- Each built-in or custom design system has a **value for every named role**. A theme translator writes those values for its generation format.
- **Every theme value has a role** of V-1. A **colour or a font the user puts in the theme** of a deck **takes the place of a value with a role**; there is **no theme value without a role**.
