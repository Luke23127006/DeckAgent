## Yêu cầu

DeckAgent phải tạo file tải về hợp lệ ở mỗi định dạng của D-031.

## Bối cảnh / Lý do

File chỉ có giá trị khi thực sự mở được, không chỉ đúng đuôi file mà hỏng bên trong.

## Acceptance

1. Khi người dùng tải deck về dạng PPTX, file PPTX mở được và sửa được chữ, hình khối và bảng trong `Microsoft PowerPoint`.
2. Khi người dùng tải deck về dạng PDF, file PDF mở được bằng trình xem PDF.
3. Khi người dùng tải deck về dạng PNG, file .zip chứa mỗi slide một ảnh PNG kích thước 1920×1080 px [tạm 2026-10-03 · xem lại: buổi thử người dùng đầu tiên có người mở file PNG tải về], và mỗi ảnh mở được bằng trình duyệt.
4. Khi người dùng tải deck về dạng SVG, file .zip chứa mỗi slide một ảnh SVG, và mỗi ảnh mở được bằng trình duyệt.

## Ghi chú

1. `Google Slides` và `LibreOffice` nằm ngoài cam kết V1.
2. Mức tương thích của file PPTX với `Microsoft PowerPoint`, ngoài các thao tác ở Acceptance 1, được học từ file thật sau implementation.
