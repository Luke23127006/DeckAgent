## Yêu cầu

Khi người dùng đưa một file vào, DeckAgent phải xác định vai trò của file đó theo mục đích sử dụng, không suy ra cứng từ đuôi file.

## Bối cảnh / Lý do

Cùng một file PPTX có thể là deck có sẵn cần sửa, tài liệu có sẵn để lấy nội dung, deck mẫu hoặc chỉ để lấy hình ảnh.

## Acceptance

1. Hệ thống phân biệt yêu cầu của người dùng với nội dung tài liệu có sẵn.
2. Hệ thống không gán vai trò của file theo đuôi file (BR-001 mệnh đề 2).

## Ghi chú

1. Vai trò deck có sẵn, deck mẫu và file lấy hình ảnh chưa bắt buộc trong V1.
