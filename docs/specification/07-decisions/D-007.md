## Decision

Vai trò của file được xác định theo mục đích sử dụng, không suy ra cứng từ đuôi file (BR-001).

## Context

1. Cùng một file có thể là tài liệu có sẵn, deck mẫu, hình ảnh để chèn hoặc vai trò khác tùy luồng.

## Phương án đã xét

| Phương án | Chọn / Loại | Lý do |
|---|---|---|
| Xác định vai trò của file theo mục đích sử dụng | Chọn | Tránh việc nhiều luồng hợp lệ bị khóa ngay từ đầu (Rationale 1) |
| Suy vai trò cứng từ đuôi file: PPTX là deck cần sửa, PDF là tài liệu có sẵn, ảnh là hình để chèn | Loại | Nhiều luồng hợp lệ bị khóa ngay từ đầu (Rationale 1) |

## Rationale / Evidence

1. Nếu kiến trúc mặc định PPTX là deck cần sửa, PDF là tài liệu có sẵn hoặc ảnh là hình để chèn, nhiều luồng hợp lệ bị khóa ngay từ đầu.
