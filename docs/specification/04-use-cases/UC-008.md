## Tình huống

Tôi có deck đã ổn cho buổi trình bày chiều nay trên máy phòng họp, tôi muốn tải về một file PPTX và một bản PDF, để chỉnh thêm vài chỗ trong `PowerPoint` và gửi trước bản PDF cho sếp.

## Mục tiêu

Người dùng có file theo định dạng đã chọn, đúng với deck đã xem trước, để dùng ngoài Hệ thống.

## Trigger

Người dùng mở xem trước deck hiện tại (UC-015).

## Preconditions

1. Lần làm việc có deck ở bản đã chấp nhận hoặc có bản chờ duyệt.

## Main Flow

1. Người dùng xem trước deck (UC-015).
2. Người dùng chọn tải về và chọn một trong 4 định dạng của D-031.
3. Hệ thống kiểm tra các thành phần không giữ được trong định dạng đã chọn.
4. Hệ thống tạo file từ đúng bản đang xem trước, không để AI tạo lại nội dung (BR-006).
5. Hệ thống kiểm tra file mở được (R-027).
6. Người dùng nhận file; với PNG và SVG, file nhận được là một file .zip.

## Alternative / Failure Flows

1A. Người dùng gửi yêu cầu sửa thay vì chọn tải về: Hệ thống chuyển sang UC-004.
3A. Định dạng đã chọn không giữ được một phần deck: Hệ thống liệt kê phần sẽ bị mất hoặc thay đổi (BR-013); người dùng chọn tiếp tục, quay lại bước 4.
3B. Người dùng chọn hủy sau danh sách ở 3A: Hệ thống giữ bản chờ duyệt là bản chờ duyệt (BR-010), kết thúc Use Case.
4A. Hệ thống tạo file thất bại: Hệ thống báo lỗi, không giao file hỏng; bản đã chấp nhận và bản chờ duyệt giữ nguyên, kết thúc Use Case.
5A. File vừa tạo không mở được: Hệ thống báo lỗi, không giao file hỏng; bản đã chấp nhận và bản chờ duyệt giữ nguyên, kết thúc Use Case.
6A. File được tạo từ bản chờ duyệt: Hệ thống chuyển bản chờ duyệt thành bản đã chấp nhận (BR-010), kết thúc Use Case.

## Postconditions

1. File được tạo từ đúng bản người dùng đã xem trước (BR-006).
2. Bản người dùng đã tải về là bản đã chấp nhận (BR-010).
3. File tải về giữ facts, số liệu, thứ tự trình bày và ý nghĩa của deck (R-025).
4. Chữ, hình khối và bảng trong file PPTX sửa được trong `PowerPoint`.

## Bảo đảm tối thiểu

1. Bản chờ duyệt chỉ trở thành bản đã chấp nhận khi tải về thành công (BR-010).

## Sản phẩm tham khảo

1. `Claude Design`: tải về PDF, URL, PPTX, HTML; gửi sang `Canva`.
2. `Gamma`: tải về PDF, PPTX, PNG, `Google Slides`; báo giới hạn bố cục khi tải PPTX.
3. `Presenton`: tải về PPTX, PDF, PNG.
4. `OpenSlide`: tải về PDF và PPTX.

## Ghi chú

1. V1 có 4 định dạng tải về (D-031); đẩy deck lên `Google Drive` thuộc release Later (R-058).
2. Chỉnh tay chuyên sâu làm trong `PowerPoint` sau khi tải về, nên file PPTX phải sửa được.
3. File tải về là cách duy nhất giữ deck sau khi lần làm việc kết thúc (BR-012).
4. V1 không dừng được lượt tạo file tải về (D-029).
