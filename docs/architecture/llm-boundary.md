# LLM boundary

Where DeckAgent calls the AI model, and where prebuilt, deterministic parts do the work
instead. This boundary is what DeckAgent adds on top of a plain model: the model
understands the request, interviews the user and writes content; themes, layouts,
animations and format renderers are prepared in advance and applied by code.

This page describes the system as built. It is updated at the end of every build.
