## Rule

- **Statement:** The rule sets the **design system a deck uses when the user chose none**.
- **Status:** confirmed

## Values

### V-1 · Default design system

- **Value:** **DeckAgent Neutral**, built-in identity `deckagent-neutral@1`.

## Notes

- The default is a **fixed built-in design system**. The user **does not make another design system the default**.
- Its theme uses the **named roles** of the [theme rule](BR-017.md). Each available generation format has a theme translator for it.
