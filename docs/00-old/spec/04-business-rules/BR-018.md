## Rule

- **Statement:** The rule sets the **built-in templates of each available generation format**, and the **template a deck uses when the user chose none**.
- **Status:** confirmed
- **Why:** **Built-in layouts** give decks a **consistent structure** while the model chooses a layout that **fits recorded content**.

## Values

### V-1 · Built-in templates of each generation format

- **Value:** **HTML** has **HTML Basic**, built-in identity `html-basic@3` for new visual selections.

### V-2 · Default template of each generation format

- **Value:** **HTML** uses **HTML Basic** by default.

## Notes

- **Every template is built in**. There is **no template the user saves**.
- HTML Basic holds **cover, section, title-body, two-column, key-figures, image-text and image-pair** layouts. Each layout states its **content kinds and capacity**.
- The **image-pair** layout holds **two images** and **up to two optional bullets**.
- A confirmed deck keeps its **selected template version**. Versions `html-basic@1` and `html-basic@2` stay available for that choice.
- HTML Basic version 3 **keeps layout structure and geometry** in its built-in template.
- Content beyond a layout's capacity requires an **Outline revision**. It does not enter a custom layout or lose required content.
- These values **add no other available generation format**.
