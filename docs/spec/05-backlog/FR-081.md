## What it is

The user **changes the settings of one added model**: its **context window**, its **highest output**, the **kinds of input** it takes and its **reasoning levels**. The system **keeps what the user saved**, **fills in no value nobody gave**, and **applies the change from the next request**.

## Belongs to

UC-005 (set up the services DeckAgent uses with my own keys).

## Why parked

The spec **takes model settings from the model catalog** of the provider; the user **gives none by hand**.

## Reconsider when

The runtime research finds that **OpenCode gives no model catalog**.
