title: "Show the context usage of a chat"
---

## What it is

The user **sees how much of the context** of the selected model the **conversation and the draft** of a chat use. The system says whether each number is an **estimate of DeckAgent** or one the **provider reported**, and **invents no number it cannot compute**. **Seeing the usage changes no conversation, draft or attachment**. It **shows usage only**; it **suggests no summary**, since the **system summarizes by itself** (FR-079).

## Belongs to

UC-003 (send a request and wait for its work).

## Why parked

The system **summarizes the conversation by itself** when it outgrows the context (FR-079), so the user **needs no number to decide when to summarize**. The **OpenCode docs show no context usage** to read from.

## Reconsider when

Runtime research shows that **OpenCode reports context usage per session**, or **users ask to see how full a chat is**.

## Findings

- **Context usage is not documented in OpenCode**.
- **Open**: does **each provider report a context usage per model**, and **which numbers are exact**?
