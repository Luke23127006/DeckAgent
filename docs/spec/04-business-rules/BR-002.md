---

## Rule

- **Statement:** The rule sets the **maximum length of the request text**. **Only the request text counts** toward the length; the **content of attached files does not**.
- **Status:** confirmed

## Values

### V-1 · Maximum length of the request text

- **Value:** At most **16,000 Unicode code points**, including the limit. Spaces and line endings count. A combining mark counts on its own. The system **does not truncate** text that exceeds the limit.
