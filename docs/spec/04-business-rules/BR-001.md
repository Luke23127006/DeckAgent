title: "Attachments the system accepts"
---

## Rule

- **Statement:** The rule sets **which files the system accepts as attachments**: their **types**, their **number** and their **size**. The **number counts the new attachments of one request**; attachments sent with earlier requests **do not count again**. The **size counts for each file on its own**.
- **Status:** confirmed

## Values

### V-1 · Accepted file types

- **Value:** **Closed list**: TXT, MD, PDF, DOCX, PNG, JPEG, PPTX and ZIP. A JPEG file ends in `.jpg` or `.jpeg`.

### V-2 · Number of new attachments in one request

- **Value:** At most **10 new attachments** in one request, including the limit. Preparing and rejected attachments count until removed from the draft.

### V-3 · Size of one attachment

- **Value:** At most **20 MiB per file**, including the limit. One MiB is **1,048,576 bytes**.
