title: "Chats kept as earlier work"
---

## Rule

- **Statement:** The rule sets which chats the system keeps as earlier work that the user can open. It also sets how long it keeps them, and which chats stay reachable when a workspace is removed.
- **Updated at:** 26-10-2026

## Values

### V-1 · Which chats are kept

- **Value:** Every chat in which the user sent at least one request. A chat with no sent request is not required to appear.

### V-2 · How long chats are kept

- **Value:** No time limit. The system deletes no chat, conversation or deck because of its age.

### V-3 · Chats of a removed workspace

- **Value:** Every chat of a workspace stays reachable after that workspace is removed. Removing a workspace changes no folder, no file of the user, no chat, no conversation and no deck on the computer. The workspace data of that workspace stays where the system keeps it.

## Notes

- No time limit is not a promise against loss that DeckAgent does not cause. Examples are files the user removes on purpose and a lost disk.
- This rule adds no way to delete a chat or a deck.
- V-3 does not say where the chats of a removed workspace appear. The use case that adds and removes workspaces names one example and leaves the decision open.
