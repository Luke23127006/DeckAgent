## Rule

- **Statement:** The rule sets the maximum length of the request text. Only the request text counts toward the length. The content of attached files does not count.
- **Updated at:** 25-10-2026

## Values

### V-1 · Maximum length of the request text

- **Value:** not set
- **Why:** No technical evidence sets the length, its unit or whether the limit is included.

## Notes

- The number and the size of attachments are separate limits of another rule.
