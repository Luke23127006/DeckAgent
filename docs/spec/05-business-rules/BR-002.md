## Rule

- **Statement:** The rule sets the maximum length of the request text. Only the request text counts toward the length. The content of attached files does not count.
- **Status:** confirmed
- **Source:** use case flow; owner decision, 2026-10-13: only the request text counts, and the content of attachments does not; the unit and the maximum wait for technical evidence
- **Updated at:** 13-10-2026

## Values

### V-1 · Maximum length of the request text

- **Value:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** No technical evidence sets the length, its unit or whether the limit is included.

## Notes

- Until 2026-10-13, an open item asked whether the text of attached files counts toward the length. The owner decision of 2026-10-13 settled it: it does not.
- The number and the size of attachments are separate limits of another rule.
