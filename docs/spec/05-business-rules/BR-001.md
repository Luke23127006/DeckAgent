## Rule

- **Statement:** The rule sets which files the system accepts as attachments: their types, their number and their size.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-11: the user can attach files, in a limited set of formats; owner decision, 2026-10-12: DeckAgent decides which attachments it accepts, and the selected model of a chat does not change it
- **Updated at:** 12-10-2026

## Values

### V-1 · Accepted file types

- **Value:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** The owner decided that the set of formats is limited, but has not chosen the formats.

### V-2 · Number of attachments

- **Value:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** A selected flow rejects a file for the number of files, but no decision sets how many the system accepts.

### V-3 · Size of an attachment

- **Value:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** A selected flow rejects a file for its size, but no decision sets the size limit or its unit.

## Not specified

- Whether the number and the size count for each request, for each chat, or for all attachments together. Pending owner decision.

## Notes

- Until 2026-10-12, an open item asked how the accepted file types relate to the model. It asked about the types that the model for the request can read. The owner decision of 2026-10-12 settled it: the accepted types do not depend on the model.
