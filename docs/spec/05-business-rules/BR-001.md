title: "Attachments the system accepts"
---

## Rule

- **Statement:** The rule sets which files the system accepts as attachments: their types, their number and their size. The number counts the new attachments of one request. Attachments sent with earlier requests of the chat do not count again. The size counts for each file on its own.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-11: the user can attach files, in a limited set of formats; owner decision, 2026-10-12: DeckAgent decides which attachments it accepts, and the selected model of a chat does not change it; owner decision, 2026-10-13: the accepted types are TXT, MD, PDF, DOCX, PNG, JPEG and PPTX; the number of new attachments is limited for each request, the size for each file, and earlier attachments of the chat do not count again
- **Updated at:** 13-10-2026

## Values

### V-1 · Accepted file types

- **Value:** Closed list: TXT, MD, PDF, DOCX, PNG, JPEG and PPTX. A JPEG file can end in `.jpg` or `.jpeg`.
- **Source:** owner decision, 2026-10-13: the accepted types are TXT, MD, PDF, DOCX, PNG, JPEG and PPTX

### V-2 · Number of new attachments in one request

- **Value:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** The owner decided that the number counts for each request. No prototype has measured how many files one request can take.

### V-3 · Size of one attachment

- **Value:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** The owner decided that the size counts for each file. No prototype has measured a size limit, and its unit is not set.

## Notes

- Until 2026-10-12, an open item asked how the accepted file types relate to the model. It asked about the types that the model for the request can read. The owner decision of 2026-10-12 settled it: the accepted types do not depend on the model.
- Until 2026-10-13, V-1 was pending, and an open item asked whether the number and the size count for each request, for each chat or for all attachments together. The owner decision of 2026-10-13 settled both.
- No limit is set for all the attachments of a chat, or for all attachments together. Such a limit needs its own owner decision.
- An accepted type is a product commitment. Reading and checking each type still needs technical tests.
- Accepting PPTX makes a deck file material for a request. It does not import the file as slides that DeckAgent can change. It does not keep every animation, effect or layout of the file. It adds no export and no direct editing of slides.
