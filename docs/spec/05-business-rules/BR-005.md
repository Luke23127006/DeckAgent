## Rule

- **Statement:** The rule sets which providers the user can add in the model setup. It also sets which models of each provider the user can add.
- **Status:** confirmed
- **Source:** use case flow
- **Updated at:** 12-10-2026

## Values

### V-1 · Providers offered

- **Value:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** A selected flow shows the providers the user can add. No decision names them or says whether the list is closed.

### V-2 · Models offered for each provider

- **Value:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** A selected flow shows the models of a provider that the user can add. No decision names them.

## Not specified

- Whether the user can add a provider or a model that is not offered. Pending owner decision.
- Whether a model that runs on the user's computer and needs no key is offered. Pending owner decision.
