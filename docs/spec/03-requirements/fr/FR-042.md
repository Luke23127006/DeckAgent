title: "Run each request with the settings it started with"
---

## Requirement

- **Statement:** A request runs with the **selected model** of its chat, the **reasoning level** of that model, and the **provider settings saved when the request starts**. It **keeps them until it ends**. A **later change** of model, reasoning level or settings **applies only to requests that start after it**, and **stops, restarts or moves no request**.
