id: FR-070
title: "Show the activities of a request"
---

## Requirement

- **Statement:** The conversation **shows the activities of a request in the order they happen**, each with **what the system did** and **its state**; **no activity is invented**, and a **failed activity does not by itself make the request fail**. The user is allowed to **read the detail of one activity** and **hide it again**, which **changes nothing in the work**. The **activities stay in the conversation** after the request ends.
