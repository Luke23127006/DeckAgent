---
id: FR-142
title: "Report a different folder at the place of a project folder"
---

## Requirement

- **Statement:** When the **place of the project folder of a workspace** holds a **folder that is not the one the user chose**, the system **says that a different folder is now there**, **names the workspace**, and **reads no file of that folder**. The user can **use that folder for the workspace**; on that choice the system **makes it the project folder** under the **same conditions as choosing another folder**. Until then, the **workspace stays set up** and **every chat of it stays readable** with its conversation and its deck.
- **Why:** A folder at the old place **looks like the chosen folder**, so "**cannot be read**" would **confuse the user**; using it **without asking** would let the agent **read files the user never chose**.

## Notes

- The **conditions of choosing another folder** are **FR-083**; a **folder that cannot be read** at all is **FR-074**.
- **Adding the different folder** as a workspace (FR-071) **sets up a new workspace** for it, since it is **not the folder of the first workspace**; the first workspace **keeps reporting a different folder**.
