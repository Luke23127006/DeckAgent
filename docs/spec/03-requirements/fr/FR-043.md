title: "Change the key or the base URL of a provider configuration"
---

## Requirement

- **Statement:** The system lets the user **replace the key** of a saved provider configuration, and **change its base URL** where the provider allows it [BR-006]. It **keeps the provider ID and the added models**, and **adds no second provider configuration**. It **checks a new key with the provider** before it saves it.
