---
id: FR-087
title: "Report work that a chat cannot save"
---

## Requirement

- **Statement:** When the system **cannot save the state of a chat**, it says that the **work was not saved** and **which change it cannot keep**: a change to the deck or the outline, or a message of the conversation. It **keeps the last saved state**, **shows that state when the chat is opened again**, and **never says that the chat holds a change it did not save**. It **starts nothing again by itself**, and **changes no other chat and no file of the user**.
