---
id: FR-040
title: "Never show any part of a saved key"
---

## Requirement

- **Statement:** **After a key is saved**, the system **never shows it again**, whole or in part, masked or not; it shows **only whether a key is saved**. The system **never shows a key in the conversation**.
- **Why:** The key **belongs to the user's own account** with the provider or the outside service.
