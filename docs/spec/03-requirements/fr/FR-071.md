---
id: FR-071
title: "Add a workspace and switch workspaces"
---

## Requirement

- **Statement:** When the user **chooses a readable folder**, the system **sets up a workspace for it**, **names it after the folder** in **NFC form** with **no space dropped** [BR-020], **cut to the longest name** [BR-020] when the folder name is longer, the **folder keeping its own name and path**, and **makes it the workspace in use**; a folder that is **already the project folder of a workspace** **makes that workspace the workspace in use**, and the system **sets up no second workspace** for it. When that folder **was moved to another place**, the workspace **takes the new place** as its project folder. **Switching to a workspace that is set up** **asks for no folder**, and a **folder that cannot be read** **sets up no workspace**. A **folder that cannot be a project folder** [BR-019] **sets up no workspace**; the system **says why** and that **a folder inside it** can be chosen when one is allowed. **Adding or switching** **keeps the current chat and its draft**, **changes no file of the user**, **reads no file of the folder**, **sends nothing to a model** and **stops no request**, and a **new chat joins the workspace in use**.

## Notes

- **Renaming a workspace** is **FR-141**. A **folder that had a removed workspace** **sets up a new workspace**; the **chats of the removed one stay ungrouped chats** (FR-073).
- **Starting a new chat** is **FR-053**.
