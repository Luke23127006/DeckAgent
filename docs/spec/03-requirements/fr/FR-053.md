id: FR-053
title: "Start a new chat"
---

## Requirement

- **Statement:** **Starting a new chat** **keeps every other chat**, its deck and its draft as they were, and **stops no request**. The new chat **becomes the current chat** in the workspace in use, with **no conversation, no deck and an empty draft**, and **takes nothing from another chat**. It gets the **selected model and the reasoning level** of the **most recent choice of a model in any chat** when that model is **still selectable** [BR-005], and **otherwise no selected model**.
- **Why:** **Carry on with the model the user chose last**, with **one simple rule**.

## Notes

- The system **does not walk back through earlier choices**. The **draft of each chat is kept whole** (FR-038). A model **removed and added again** **counts when it is selectable**. The **reach of the agent is the same for every chat** (FR-077).
- A chat holds **at most one deck** (glossary), so **another deck starts in a new chat**.
