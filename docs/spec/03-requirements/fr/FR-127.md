id: FR-127
title: "Name what changed in a revised outline"
---

## Requirement

- **Statement:** When the system **shows a revised outline**, it **names each planned slide it added, removed, moved or changed**, and **each item of the brief it changed**, **compared with the outline proposal it revised**. This **includes each change that the revision did not ask for**.
- **Why:** **Napkin AI was observed changing more slides than a revision said**, so **each change is named**.
