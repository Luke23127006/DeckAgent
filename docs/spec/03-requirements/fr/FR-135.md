## Requirement

- **Statement:** The system **reads the words and the brand files** the user gives for a design system **with a selectable model** [BR-005]. When **no model is selectable** or the **model does not answer**, it **makes no proposal**, **saves nothing**, **keeps what the user gave** and **says why**.

## Undecided

- **Which selectable model reads** the words and the brand files of the setup. **Pending decision**.
