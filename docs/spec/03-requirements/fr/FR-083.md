id: FR-083
title: "Choose another project folder for a workspace"
---

## Requirement

- **Statement:** When the user **chooses another folder for a workspace** other than the default workspace, the system **makes it the project folder** of that workspace, **keeps the workspace, its name and its chats**, **reads no file of the folder** because of the choice, and **never changes a project folder by itself**. When the chosen folder is the **project folder of another workspace**, **cannot be read** or **cannot be a project folder** [BR-019], the system **changes neither workspace** and says **which workspace uses the folder**, that it **cannot be read**, or **why it cannot be a project folder**. While a **request in a chat of the workspace is active**, the system **changes no project folder**, says that the **request must end first**, and **stops no request**. The **default workspace has no project folder**: when the user chooses a folder for it, the system **refuses**, **changes no state** and **says why**.
