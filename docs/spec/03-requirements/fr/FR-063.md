---
id: FR-063
title: "Delete a provider configuration"
---

## Requirement

- **Statement:** The system **deletes a provider configuration and its added models** **from DeckAgent only**, and **changes nothing at the provider**. It **keeps every chat and deck**. An **active request that uses it** **keeps the settings it started with** until it ends.

## Notes

- The **request keeps its settings** (FR-042), so deleting a provider configuration that an active request uses is **not refused**.
