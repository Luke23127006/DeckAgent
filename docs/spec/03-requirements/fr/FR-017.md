---
id: FR-017
title: "Reject an unusable attachment"
---

## Requirement

- **Statement:** The system **rejects an added file** that **breaks the attachment rule** [BR-001], or that is **protected, damaged or unreadable** [NFR-010]. It **rejects the file when it is added** and **shows the reason** on the attachment **at once**. The **rejected attachment stays until the user removes it**, and the **rest of the draft stays** as it was.
