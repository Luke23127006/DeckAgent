---
id: FR-074
title: "Report a project folder that cannot be read"
---

## Requirement

- **Statement:** When the **project folder of a workspace cannot be read**, the system **says so**, **names the workspace**, and says **what the user does next**, such as put the folder back, give access again or choose another folder. It **names no cause it does not know**, such as a deletion, and **reads no file of that folder** while it cannot be read. The **workspace stays set up**, and **every chat of it stays readable** with its conversation and its deck.

## Notes

- A **file of the folder that a request needs** while the folder cannot be read is **FR-067**.
- A **different folder at the place** of the project folder is **FR-142**.
