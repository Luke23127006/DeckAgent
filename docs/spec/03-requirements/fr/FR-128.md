id: FR-128
title: "Answer a question and change only what is asked"
---

## Requirement

- **Statement:** When a message **asks a question and asks for no change**, the system **answers it** and **changes no outline, brief or slide**. When a message **asks a question and also asks for a change**, the system **makes the change** and **answers the question in the closing message**, or with the revised outline before the slides. When a message **reads both as a question and as a change**, the system **asks which one the user means** and **changes nothing**.
- **Why:** A **question about an unconfirmed outline is answered**, **not taken as a revision**; a message that **also asks for a change** is **taken as that change**.
