## Who

- Analysts and research staff regularly turn data and large bodies of source material into reports.
- Decision makers read these reports before they meet.
- The readers often use several languages.
- **Evidence:** [assumed]

## Needs

### N-1 · Show the data without distortion

- **Goal:** "Show the committee what the data says without distorting it."
- **Situation:** Decisions follow from these figures. A wrong axis, unit or rounding would mislead them.
- **Use cases:** none yet
- **Evidence:** [assumed]

### N-2 · Find key findings across many sources

- **Goal:** "Pull the key findings from dozens of sources without missing the ones that matter."
- **Situation:** About 40 papers and a large spreadsheet feed each quarter's briefing.
- **Use cases:** UC-001
- **Evidence:** [assumed]

### N-3 · Show where each claim comes from

- **Goal:** "Point to where every claim comes from."
- **Situation:** Committee members ask for the source of any statement.
- **Use cases:** none yet
- **Evidence:** [assumed]

### N-4 · Rebuild next quarter quickly

- **Goal:** "Produce next quarter's briefing from new data without rebuilding it."
- **Situation:** The structure stays the same each quarter. Only the numbers and some findings change.
- **Use cases:** UC-001 (A29, structure only)
- **Evidence:** [assumed]

### N-5 · Same meaning in every language

- **Goal:** "Give readers in different languages the same numbers and meaning."
- **Situation:** Members read in several languages and compare versions across them.
- **Use cases:** none yet
- **Evidence:** [assumed]

## Knowledge

- **Domain (the topic they present):** Expert. Knows the field and sources deeply. Will notice a misread result immediately.
- **Presentation craft:** Basic. Can build plain charts and tables. Does not design visually.
- **AI / tool literacy:** Working. Uses AI assistants for summarizing and knows to check them. Has limited feel for how much input they can take.
- **Language of use (what they write requests in):** Expert. Writes requests fluently in a professional working language.
- **Language of the deck and its audience:** Working. Is confident in the main language of the deck. Is less sure how the wording reads to readers of other languages.
- **Evidence:** [assumed]

## Context of use

- Works at a desktop, over days each quarter.
- Works alone or with a reviewing colleague.
- The source material is a large spreadsheet and many papers. It is far longer than a normal prompt.
- Sends the briefing to the committee to read before the meeting. Does not present it slide by slide.
- The findings may be unpublished.
- The segment has not stated a rule for how data may be used (see open questions).
- **Evidence:** [assumed]

## Pain points and workarounds today

- Summarizes papers one by one into a notes file, then copies the notes into slides.
- Retypes numbers from the spreadsheet into charts and loses track of which version is current.
- Rebuilds the briefing from scratch each quarter. The old file is tied to last quarter's data.
- Keeps separate files per language and finds that numbers drift apart between them.
- **Evidence:** [assumed]

## Special-case hypotheses

### H-1 · Numbers must match the source

- **Situation:** Figures, units, rounding and labels must match the source tables exactly.
- **Product would have to:** Treat numbers as data to carry over exactly, not as text to rewrite.
- **Affects:** Data fidelity; charts; number accuracy
- **Handled by:** none yet
- **Evidence:** [assumed]

### H-2 · Input too big for one prompt

- **Situation:** Source material (dozens of papers and a large spreadsheet) exceeds any single input.
- **Product would have to:** Accept many or large inputs. Say plainly what it read, what it skipped and why.
- **Affects:** Input volume and limits; coverage reporting
- **Handled by:** UC-003.A3 (input volume only)
- **Evidence:** [assumed]

### H-3 · Claims must link to sources

- **Situation:** Committee members ask where a claim came from.
- **Product would have to:** Link each claim back to a source passage.
- **Affects:** Source tracing; citation
- **Handled by:** none yet
- **Evidence:** [assumed]

### H-4 · Quarterly rebuild

- **Situation:** The same briefing is rebuilt each quarter.
- **Product would have to:** Let the user update numbers and findings while keeping structure and layout.
- **Affects:** Reusing a previous deck; updating data
- **Handled by:** UC-001.A29 (structure only)
- **Evidence:** [assumed]

### H-5 · Language versions must agree

- **Situation:** Readers compare versions in several languages.
- **Product would have to:** Keep numbers, layout and meaning consistent across language versions.
- **Affects:** Multi-language versions; consistency
- **Handled by:** none yet
- **Evidence:** [assumed]

### H-6 · Wide tables do not fit

- **Situation:** Tables with many columns cannot all fit on a slide.
- **Product would have to:** Decide what to show, split or leave to an appendix. Let the user override the decision.
- **Affects:** Dense tables; layout decisions
- **Handled by:** none yet
- **Evidence:** [assumed]
