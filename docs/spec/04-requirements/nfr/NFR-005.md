---
id: NFR-005
title: "Access only from the computer that runs DeckAgent"
---

## Requirement

- **Quality attribute:** security
- **Statement:** Only the user at the computer that runs DeckAgent can use it. No other device can read or change its chats, decks or provider configurations. No other device can start a request. Another website in the same browser cannot do any of these either.
- **Updated at:** 25-10-2026

## Verification

### M-1 · Another device on the same network

- **Conditions:** DeckAgent runs on computer C. C holds chats, decks and a saved provider configuration. Device D is on the same local network as C. Boundary: product-controlled. Provider-dependent conditions: none.
- **Measure:** Whether D can read or change a chat, a deck or a provider configuration on C. Whether D can start a request.
- **Method:** From D, try each way to reach DeckAgent on C that the network allows. Compare the data on C before and after. Check whether a request started.
- **Target:** D can do none of these.
- **Met when:** Every attempt fails.

### M-2 · Another website in the same browser

- **Conditions:** DeckAgent runs on computer C. The user opens another website in the same browser that shows DeckAgent. The site tries to reach DeckAgent on C. It also tries through a web address that later points to C. Boundary: product-controlled. Provider-dependent conditions: none.
- **Measure:** Whether the site can read or change a chat, a deck or a provider configuration. Whether the site can start a request.
- **Method:** Serve test sites that try each known way for a website to reach a program on the user's computer. Compare the data on C before and after. Check whether a request started.
- **Target:** The site can do none of these.
- **Met when:** Every attempt fails.

## Notes

- This requirement applies to the whole product.
- Access from another device stays outside the reach of the product. It is a security constraint of the statement, not of an architecture choice.
- How DeckAgent limits access is an architecture matter.
