id: NFR-012
title: "Wait for a change to the deck"
---

## Requirement

- **Quality attribute:** performance
- **Statement:** After the user sends a clear request to change the deck, the changed deck soon shows in the deck canvas. The wait is measured end to end, so it includes the time of the model provider.
- **Status:** confirmed
- **Source:** owner decision, 2026-10-13: the requirement is kept as written, with its end-to-end boundary; no time is set before a prototype or a decision
- **Why:** A change needs the model, so the wait is measured end to end. Trade-off: the target depends on the provider and the model, so it holds only under named conditions.
- **Updated at:** 13-10-2026

## Verification

### M-1 · Change to one named slide

- **Conditions:** A chat with a deck of five slides from a finished first draft. No request is active. The user sends "make slide 3 shorter". Boundary: end-to-end, as the statement says. Provider-dependent conditions: the provider, the model and the response time of the provider. Every run names the provider and the model. Every run uses the same computer, and the report names it.
- **Measure:** The time from sending the request to the end of the work. The work ends when the deck canvas shows the changed slide, and the system says it is done.
- **Method:** Send the same request from the same deck many times for each provider and model. Observe both moments as the user sees them, with one clock. Report each provider and model apart.
- **Target:** not set
- **Met when:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** No decision sets the time, or the share of runs that must meet it.

### M-2 · Change to the whole deck

- **Conditions:** As in M-1. The user sends "make the whole deck more formal".
- **Measure:** The time from sending the request to the end of the work. The work ends when the deck canvas shows every changed slide, and the system says it is done.
- **Method:** As in M-1.
- **Target:** not set
- **Met when:** not set
- **Status:** pending
- **Source:** owner decision needed
- **Why:** No decision sets the time, or the share of runs that must meet it.
