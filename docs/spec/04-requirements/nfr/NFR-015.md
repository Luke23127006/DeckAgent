---
id: NFR-015
title: "Visual fidelity of static deck export"
---

## Requirement

- **Quality attribute:** display integrity
- **Statement:** Each page or image of a static export keeps what the deck canvas shows for its slide: the visible content, the slide order and the layout. No text is cut off by mistake and no image is missing.
- **Updated at:** 28-10-2026

## Verification

### M-1 · Fidelity to the deck view

- **Conditions:** A fixed, stable deck with finished slides, whose fonts and media are available. Each of PDF, PNG and JPEG is exported from that same deck state [BR-012]. Boundary: product-controlled. Provider-dependent conditions: the model and the provider shaped the source deck, but the source is held fixed during this comparison. Provider time is not part of it.
- **Measure:** The visible content, the slide order, the typography, the images, the dimensions, the relative positions and any clipping, compared with the slide as the deck canvas shows it.
- **Method:** Open each exported page or image and the matching slide from the same stable deck state. Compare the listed properties slide by slide. Do not change the source deck.
- **Target:** Every exported page or image keeps all important visible content, the slide order and the relative layout of its slide. No text is cut off by mistake and no image is missing.
- **Met when:** Every page or image in each tested output meets the target.

## Notes

- A static export does not play animations or run interactions. This requirement does not promise them.
