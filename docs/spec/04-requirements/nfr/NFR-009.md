---
id: NFR-009
title: "Slide display integrity"
---

## Requirement

- **Quality attribute:** display integrity
- **Statement:** Each finished slide shows in full in the deck canvas. Its text is not cut off and does not run outside the slide. No content covers other content so that it cannot be read. Each image, font and other resource the slide uses shows. Its characters show correctly in the language of the deck.
- **Updated at:** 25-10-2026

## Verification

### M-1 · Text inside the slide

- **Conditions:** Finished slides from first drafts and from changes to decks. The requests vary in length and kind. Slides are shown in the deck canvas, also after a chat is opened again. Boundary: end-to-end, because the model writes the content of a slide. Provider-dependent conditions: the provider and the model. Each run names them and the computer.
- **Measure:** The share of finished slides with any text cut off or outside the slide.
- **Method:** For each slide, compare the text the slide holds with the text that shows. Compare the place of each text with the bounds of the slide. Report each provider and model apart.
- **Target:** not set
- **Met when:** not set
- **Why:** No decision has set a target yet. No prototype has measured how often text runs outside a slide.

### M-2 · No content hidden by other content

- **Conditions:** As in M-1.
- **Measure:** The share of finished slides on which some content covers other content so that it cannot be read.
- **Method:** For each slide, compare the area of each text and image with the others. A person judges each overlap the comparison finds.
- **Target:** not set
- **Met when:** not set
- **Why:** No decision has set a target yet. No prototype has measured how often content overlaps.

### M-3 · Resources show

- **Conditions:** Finished slides that use images from attachments, new images and the fonts and images of the default design system [BR-003]. Slides are shown in the deck canvas, also after DeckAgent opens again. Boundary: product-controlled. Provider-dependent conditions: none change the result. A model service returns fixed slide content and fixed new images.
- **Measure:** Whether any image, font or other resource that a slide uses does not show.
- **Method:** List the resources that each slide uses. Check that each one shows in the deck canvas.
- **Target:** No resource is missing.
- **Met when:** Every slide meets the target.

### M-4 · Characters of the languages checked first

- **Conditions:** Finished slides with text in Vietnamese and in English, with the accents and marks of each language. These are the languages checked first. They are not a full list of the languages DeckAgent writes in. Boundary: product-controlled. Provider-dependent conditions: none change the result. A model service returns fixed text.
- **Measure:** Whether any character shows as a sign for a missing character, a blank or another character.
- **Method:** Compare the characters each slide holds with the characters that show.
- **Target:** Every character shows as itself.
- **Met when:** Every slide meets the target.

## Notes

- The size and the contrast of text are not covered here. The design system sets them.
- A slide that is empty or not finished is covered by behavior requirements, not by this one.
- How DeckAgent makes a new image is not set by this requirement.
