---
id: NFR-008
title: "Saved state after an unexpected end"
---

## Requirement

- **Quality attribute:** data integrity
- **Statement:** When DeckAgent ends unexpectedly, the last saved state of each chat and its deck is kept. So is the last saved state of the model setup. After DeckAgent opens again, each chat opens and can be used in its last saved state. No unfinished change to a slide shows as a finished result.
- **Status:** confirmed
- **Source:** owner decision, 2026-10-13: DeckAgent protects the last saved state of chats and decks when it ends unexpectedly; after it opens again, chats and decks can be used in their saved state, and no unfinished change to a slide counts as a finished result; no promise is made that every result shown just before the end was saved; owner decision, 2026-10-13: saved provider configurations, added models and selected models get the same protection
- **Updated at:** 13-10-2026

## Verification

### M-1 · Chats and decks at their last saved state

- **Conditions:** Several chats with conversations, attachments, confirmed outlines and decks. DeckAgent makes the last saved state of each chat readable for this check. DeckAgent is ended at chosen and at random moments. The moments include no work, building slides, changing slides and saving. DeckAgent is ended in two ways: its program is killed, and the computer loses power. Boundary: product-controlled. Provider-dependent conditions: none change the result. A model service returns fixed content at a fixed pace.
- **Measure:** After DeckAgent opens again: whether each chat opens and accepts a new request. Whether its conversation, outline and deck equal its last saved state before the end. Whether any slide shows an unfinished change.
- **Method:** At each end, take the last saved state of each chat. Open DeckAgent again and open every chat. Compare each chat with that state. A chat that shows an older state fails. Look for unfinished changes. Repeat many times for each way to end.
- **Target:** Every chat opens and accepts a new request. Each chat equals its last saved state. No slide shows an unfinished change.
- **Met when:** Every run meets the target.

### M-2 · Model setup at its last saved state

- **Conditions:** Saved provider configurations with added models. Chats with selected models. DeckAgent makes the last saved state of the model setup readable for this check. DeckAgent is ended at chosen and at random moments, also while the user saves a change to the model setup. Boundary: product-controlled. Provider-dependent conditions: none.
- **Measure:** Whether each provider configuration, its added models and each selected model equal their last saved state before the end.
- **Method:** At each end, take the last saved state of the model setup. Open DeckAgent again and compare the model setup with that state. An older state fails. Repeat many times.
- **Target:** Each one equals its last saved state. None is damaged.
- **Met when:** Every run meets the target.

## Notes

- A saved state is a state that DeckAgent has kept so that it survives an end. The check needs DeckAgent to show which state that is. How DeckAgent shows it is an architecture matter.
- The owner decision makes no promise that a result shown just before the end was saved. An unexpected end can lose recent work. No limit is set on how much.
- Request text and attachments that the user did not send are not covered.
- What a reopened chat says about a request that did not finish is behavior, not this requirement.
- How and when DeckAgent saves is an architecture matter.
