---
id: FR-050
title: "Report a chat that cannot be opened"
---

## Requirement

- **Statement:** When a chosen chat cannot be opened, the system says so, and says why when it knows the reason. It changes no other chat. The current chat stays as it was.
- **Updated at:** 25-10-2026

## Acceptance conditions

### AC-1 · Other chats stay as they were

- **Given:** Earlier chats X and Y. What the system kept for chat X is missing. The user is in chat Z, which has a deck of three slides.
- **When:** The user chooses to open chat X.
- **Then:**
  - Chat Z is still the current chat, with the same conversation, request area and deck.
  - The user can open chat Y. Its conversation and its slides are the same as before.
- **Check:** deterministic

### AC-2 · The user is told why

- **Given:** The state after AC-1.
- **When:** The user reads the response.
- **Then:**
  - The response says that chat X cannot be opened.
  - The response says that what was kept for chat X is missing.
- **Check:** judged

## Notes

- This requirement sets no repair of a chat that cannot be opened.
