id: FR-053
title: "Start a new chat"
---

## Requirement

- **Statement:** Starting a new chat keeps the current chat as it was, with its conversation and its deck. The system makes a new chat the current chat, with an empty conversation, no deck and an empty request area. The new chat takes nothing from an earlier chat, and the system builds no deck by itself. The user can send a request for a first draft in it.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-11: one default workspace, and a new chat for another deck
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · The new chat is empty

- **Given:** The user is in chat X, with a conversation and a deck of five slides. No request is active.
- **When:** The user starts a new chat.
- **Then:**
  - A new chat is the current chat.
  - Its conversation has no message.
  - Its deck has no slide.
  - Its request area holds no request text and no attachment.
  - No request starts.
- **Check:** deterministic

### AC-2 · The earlier chat stays

- **Given:** The state after AC-1.
- **When:** The user opens chat X again.
- **Then:**
  - The conversation of chat X is the same as before the new chat started.
  - The five slides of chat X are the same as before.
- **Check:** deterministic

### AC-3 · A first draft starts in the new chat

- **Given:** The state after AC-1.
- **When:** The user sends "a talk on our staff survey".
- **Then:**
  - The system responds with an outline proposal before it builds any slide.
- **Check:** deterministic

### AC-4 · Nothing comes from the earlier chat

- **Given:** The state after AC-3. Chat X is about the results of a hospital pilot.
- **When:** The user reads the outline proposal of the new chat.
- **Then:**
  - The proposal uses no content of chat X, such as its pilot results.
- **Check:** judged

## Not specified

- What happens to request text the user did not send in the earlier chat. Pending owner decision.

## Notes

- Starting a new chat during an active request is covered by FR-054. Whether an empty new chat counts among earlier chats is a value of BR-004.
