---
id: FR-036
title: "Refuse a slide reference that does not match the deck"
---

## Requirement

- **Statement:** A request to change the deck can name a slide that is not in the deck. Or it can give a slide number and a slide title that point to different slides. The system then changes no slide and says which part of the request does not match the deck. It says how many slides the deck has. It keeps the sent request in the conversation, unchanged, and does not send it again by itself. The user can send a new request with a corrected slide reference.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-12: the user corrects a slide reference through a new request; a sent request cannot be taken back or changed
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · Slide not in the deck changes nothing

- **Given:** A deck of five slides. No request is active.
- **When:** The user sends "make slides 2 and 9 shorter".
- **Then:**
  - Every slide is the same as before the request, slide 2 included.
  - The deck has five slides.
  - The user's message is in the conversation, the same as when it was sent.
  - The system no longer shows that it works on the request.
  - The system does not send the request again by itself.
- **Check:** deterministic

### AC-2 · Message names the mismatch and the size of the deck

- **Given:** The state after AC-1.
- **When:** The user reads the response.
- **Then:**
  - The response says that slide 9 is not in the deck.
  - The response says that the deck has five slides.
- **Check:** judged

### AC-3 · Number and title that disagree change nothing

- **Given:** A deck of five slides. Slide 3 has the title "Results". Slide 4 has the title "Costs". No request is active.
- **When:** The user sends "make slide 3, Costs, shorter".
- **Then:**
  - Every slide is the same as before the request.
- **Check:** deterministic

### AC-4 · No slide is chosen for the user

- **Given:** The state after AC-3.
- **When:** The user reads the response.
- **Then:**
  - The response says that slide 3 and the title "Costs" point to different slides.
  - The response does not present slide 3 or slide 4 as the slide it changed or will change.
- **Check:** judged

### AC-5 · Corrected reference in a new request

- **Given:** The state after AC-1.
- **When:** The user sends a new request, "make slides 2 and 4 shorter".
- **Then:**
  - The conversation shows the new request as a new user's message.
  - The first request shows once in the conversation, the same as when it was sent.
  - The system offers no way to take back or change the first request.
  - Slides 1, 3 and 5 are the same as before the new request.
- **Check:** deterministic

## Notes

- A request that names a matching slide but does not say what to change is covered by FR-035.
- How the new request changes slides 2 and 4 is covered by FR-027.
