---
id: FR-062
title: "Restore the default models after the user confirms"
---

## Requirement

- **Statement:** The user can restore the default models of a provider configuration whose built-in provider has default models [BR-005]. Before any change, the system says that restoring can replace the added models and asks the user to confirm. When the user cancels, the added models stay as they were. When the user confirms, each default model becomes an added model of that provider configuration. Restoring changes no other provider configuration, selects no model for any chat, and runs no model.
- **Status:** confirmed
- **Source:** owner decision, 2026-10-12: the user can restore the default models of a provider where defaults exist; the system asks for confirmation before it replaces the user's model list, and a cancel keeps the list
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · Nothing changes before the confirmation

- **Given:** "Work AI" for the built-in provider P is saved. The default models of P are D1 and D2 [BR-005]. "Work AI" has the added models D1 and M9. The user removed D2 and gave M9 by hand.
- **When:** The user chooses to restore the default models of "Work AI".
- **Then:**
  - The system asks the user to confirm.
  - "Work AI" still has the added models D1 and M9.
- **Check:** deterministic

### AC-2 · Cancelling keeps the added models

- **Given:** The state after AC-1.
- **When:** The user cancels.
- **Then:**
  - "Work AI" has the added models D1 and M9.
  - D2 is not an added model of "Work AI".
- **Check:** deterministic

### AC-3 · Confirming restores the default models

- **Given:** The state after AC-1. "Lab" is a custom model API with the added model M1. A test account with P records each request it receives.
- **When:** The user confirms.
- **Then:**
  - D1 and D2 are added models of "Work AI".
  - "Lab" still has the added model M1.
  - P has received no request that runs a model.
- **Check:** deterministic

### AC-4 · No chat gets another model

- **Given:** The state after AC-1. Chat X has M9 of "Work AI" as its selected model. Chat Y has D1 of "Work AI".
- **When:** The user confirms.
- **Then:**
  - The system has selected no other model in chat X.
  - Chat Y still has D1 of "Work AI" as its selected model.
- **Check:** deterministic

### AC-5 · The user is warned

- **Given:** The state after AC-1.
- **When:** The user reads the request to confirm.
- **Then:**
  - It says that restoring can replace the added models of "Work AI".
- **Check:** judged

### AC-6 · A provider with no default models

- **Given:** "Lab" is a custom model API with no default models [BR-005]. It has the added model M1.
- **When:** The user looks for a way to restore the default models of "Lab".
- **Then:**
  - The system does not let the user restore default models for "Lab".
  - "Lab" still has the added model M1.
- **Check:** deterministic

## Not specified

- Whether the added models that are not default models stay after a confirmed restore. Pending owner decision.

## Notes

- A chat whose selected model is no longer an added model chooses again before its next request, as FR-056 says.
