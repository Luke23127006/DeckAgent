---
id: FR-120
title: "Preserve deck content and layout during export"
---

## Requirement

- **Statement:** An export keeps the meaning, the important facts and figures, the slide order, and the visuals and layout of each slide as the deck canvas shows them [NFR-015]. It never redesigns, reflows or resizes a slide, and never changes the deck, to make the export work. When the chosen output would lose important content, the system names the loss before it gives any file. The user then accepts the stated loss or chooses another output. The system never drops important content silently.
- **Updated at:** 28-10-2026

## Acceptance conditions

### AC-1 · Slides keep their content and layout

- **Given:** A deck of five finished slides with text, a chart and two images.
- **When:** The user exports it as PDF.
- **Then:**
  - Each page shows the text, the chart and the images of its slide, in the same places relative to each other [NFR-015].
  - The slide order is the same.
- **Check:** judged

### AC-2 · The deck does not change

- **Given:** The state of AC-1.
- **When:** The export ends.
- **Then:**
  - Each slide of the deck is the same as before the export.
  - The native source of the deck is the same as before the export.
- **Check:** deterministic

### AC-3 · A loss of information is named before delivery

- **Given:** A deck whose slide 3 shows its last two points only through an animation.
- **When:** The user chooses a PDF export.
- **Then:**
  - Before any file is given, the system names slide 3 and says that the points shown by the animation are lost.
  - The system asks the user to accept the loss or to choose another output.
  - No file is given before the answer.
- **Check:** deterministic

### AC-4 · An accepted loss is reported

- **Given:** The state of AC-3.
- **When:** The user accepts the loss.
- **Then:**
  - The system gives the file.
  - The conversation names the loss the user accepted.
- **Check:** deterministic

### AC-5 · A loss that is not accepted gives no file

- **Given:** The state of AC-3.
- **When:** The user does not accept the loss.
- **Then:**
  - No file is written.
  - The system does not say that the export finished.
- **Check:** deterministic
