id: FR-024
title: "Closing message of the first draft"
---

## Requirement

- **Statement:** When the first draft is done, the system shows a closing message that says the draft is ready. The message tells what was made for each slide, which assumptions were used and which text is placeholder. It also tells which content did not come from the user's material [BR-?: disclosure of content not from the user's material], and what the system did not check. For each figure taken from the material, it names the part the figure comes from [BR-?: how a source is named]. It says that naming a source does not mean the system checked the claim.
- **Status:** confirmed
- **Source:** use case flow
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · Closing message follows the last slide

- **Given:** A chat with a first draft of four slides. The request was "a talk on our ward's hand hygiene pilot, from these notes". The system asked who the audience is, and the user skipped the question. In the confirmed outline, the point on the cost savings is a placeholder. The notes say that missed hand washes fell from 40 to 30 a week. Slide 2 explains why hand hygiene prevents infections, from general knowledge. The system did not check the figures in the notes against any other source.
- **When:** The system finishes the last slide.
- **Then:**
  - The conversation shows a closing message of the system after the last slide is done.
- **Check:** deterministic

### AC-2 · What was made for each slide

- **Given:** The state of AC-1.
- **When:** The user reads the closing message.
- **Then:**
  - For each of the four slides, the message tells what the slide holds.
- **Check:** judged

### AC-3 · Assumptions are named

- **Given:** The state of AC-1.
- **When:** The user reads the closing message.
- **Then:**
  - The message names the audience that the system assumed.
- **Check:** judged

### AC-4 · Placeholder text is named

- **Given:** The state of AC-1.
- **When:** The user reads the closing message.
- **Then:**
  - The message says that the text on the cost savings is a placeholder.
- **Check:** judged

### AC-5 · Content not from the material is named

- **Given:** The state of AC-1.
- **When:** The user reads the closing message.
- **Then:**
  - The message shows that the point on why hand hygiene prevents infections did not come from the notes.
- **Check:** judged

### AC-6 · What was not checked is named

- **Given:** The state of AC-1.
- **When:** The user reads the closing message.
- **Then:**
  - The message says that the system did not verify the figures against another source.
- **Check:** judged

### AC-7 · Source of a figure, not presented as checked

- **Given:** The state of AC-1. A slide gives the fall in missed hand washes.
- **When:** The user reads the closing message.
- **Then:**
  - The message names the part of the notes that the figure on missed hand washes comes from.
  - The message says that naming that part does not mean the system checked the figure.
- **Check:** judged

### AC-8 · Message says the draft is ready

- **Given:** The state of AC-1.
- **When:** The user reads the closing message.
- **Then:**
  - The message says that the draft is ready.
- **Check:** judged

## Not specified

- How the message names the part of the material that a figure comes from. Pending owner decision.
