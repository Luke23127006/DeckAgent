---
id: FR-107
title: "Change slide design while preserving content"
---

## Requirement

- **Statement:** When the user asks only for a design change, the system changes the design of the requested slides. Each changed slide keeps its information, figures, facts and meaning. The slide count, the slide order and the structure of the deck stay as they were unless the user asks otherwise. The system changes no saved design system or visual style.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · Only the requested slide changes

- **Given:** A deck has five slides. Slide 3 has the title "Results" and three findings. No request is active.
- **When:** The user sends "use the Editorial visual style on slide 3".
- **Then:**
  - The deck has five slides in the same order.
  - Slides 1, 2, 4 and 5 are the same as before the request.
  - Slide 3 keeps its title "Results" and its three findings.
- **Check:** deterministic

### AC-2 · The requested design applies

- **Given:** The state of AC-1. "Editorial" is saved.
- **When:** The system has changed slide 3.
- **Then:**
  - Slide 3 follows the layout and heading rules of "Editorial".
  - A reader can still find the three findings on slide 3.
- **Check:** judged

### AC-3 · The saved definitions stay as they were

- **Given:** The design system "Acme" and the custom visual style "Report" are saved.
- **When:** The user applies "Report" to the whole deck.
- **Then:**
  - "Acme" and "Report" hold the same rules as before the request.
  - The system saved no design system and no visual style.
- **Check:** deterministic

### AC-4 · A request for content and design follows both parts

- **Given:** A deck has five slides. Slide 3 gives four findings.
- **When:** The user sends "shorten slide 3 and use the Editorial visual style on it".
- **Then:**
  - Slide 3 is shorter than before.
  - Slide 3 follows the rules of "Editorial".
  - Slides 1, 2, 4 and 5 are as they were.
- **Check:** judged
