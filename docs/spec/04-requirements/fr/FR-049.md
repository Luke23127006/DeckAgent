id: FR-049
title: "Open an earlier chat"
---

## Requirement

- **Statement:** When the user chooses an earlier chat, the system opens it and starts no work. It shows the conversation of that chat in order. It shows the slides as they were when the user last left the chat. It changes no slide, and the user can send a new request in that chat. The chat the user left stays as it was.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-11: earlier chats and their decks stay available after DeckAgent is closed and opened again
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · The chat opens as it was left

- **Given:** Earlier chat X has a conversation of four messages and a deck of five slides. The user is in chat Z, which has a deck of three slides and no active request.
- **When:** The user opens chat X.
- **Then:**
  - No request starts.
  - The conversation shows the four messages of chat X, in the same order.
  - The deck canvas shows the five slides of chat X, the same as when the user last left it.
- **Check:** deterministic

### AC-2 · Also after a restart

- **Given:** The state of AC-1 before chat X was opened. DeckAgent was then closed and opened again.
- **When:** The user opens chat X.
- **Then:**
  - The outcomes are the same as in AC-1.
- **Check:** deterministic

### AC-3 · The chat the user left stays

- **Given:** The state after AC-1.
- **When:** The user opens chat Z again.
- **Then:**
  - The conversation of chat Z is the same as before chat X was opened.
  - The three slides of chat Z are the same as before.
- **Check:** deterministic

### AC-4 · A new request in the opened chat

- **Given:** The state after AC-1.
- **When:** The user sends "make slide 2 shorter".
- **Then:**
  - The conversation of chat X shows it as a new user's message, after the four earlier messages.
  - The system works on it in chat X.
  - The deck of chat Z is the same as before.
- **Check:** deterministic

## Not specified

- What happens to request text the user did not send in the chat they left. Pending owner decision.

## Notes

- The change the new request makes is covered by FR-027. Changing chats during an active request is covered by FR-054.
