---
id: FR-089
title: "Report unavailable public research and offer a way forward"
---

## Requirement

- **Statement:** When public research cannot provide information needed for a request, the system says what it could not obtain. It continues with available information when that still meets the request. When the missing information would materially change the result, it offers choices and waits for the user. It starts no research attempt by itself. When the user chooses another attempt, only the research operation runs again, within the same request. It never presents information it could not verify as verified.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · Important information is unavailable

- **Given:** A request requires current public figures. The research service cannot provide them. Without them, the intended result would change a lot.
- **When:** The system cannot obtain the figures.
- **Then:**
  - The system says which figures it could not obtain.
  - It offers to continue with available information, receive material from the user, or stop the request.
  - It offers another research attempt only when that operation is permitted.
  - The request waits for the user's choice.
- **Check:** judged

### AC-2 · Optional research fails

- **Given:** A request can be completed from the user's notes. Public research was optional and returned no usable information.
- **When:** The system continues the request.
- **Then:**
  - It uses the available notes.
  - It says that public research provided no usable information.
  - It does not claim that the notes were checked using public research.
- **Check:** judged

### AC-3 · The user chooses to continue without current figures

- **Given:** The state after AC-1. The user chooses to use available information without the current figures.
- **When:** The system continues the same request.
- **Then:**
  - The result identifies the unavailable figures or leaves their claims unresolved.
  - The result does not present old or unverified figures as newly verified.
- **Check:** judged

### AC-4 · The user chooses another research attempt

- **Given:** The state after AC-1. The system offered another research attempt.
- **When:** The user chooses that attempt.
- **Then:**
  - The system runs the research operation again only, in the same request.
  - It runs no other step of the request again, and it starts no new request.
  - It starts no further attempt unless the user chooses one.
- **Check:** deterministic

## Notes

- FR-020 covers waiting for the user's answer within the same request.
- FR-076 governs any operation the user has refused. A failed research operation and a refused operation are different situations.
