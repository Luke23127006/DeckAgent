---
id: FR-059
title: "Remove an added model"
---

## Requirement

- **Statement:** The user can remove an added model from a provider configuration and save. The system removes it from that provider configuration only, and deletes or changes nothing at the provider. The model is no longer selectable. A chat that selected it then has no selected model, and the system selects no other model. Adding the model again later makes it selectable, but not the selected model of any chat. The provider configuration, its other added models and every chat, request, attachment and deck stay as they were.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-12: the user can remove an added model; it changes nothing at the provider, and a chat that selected it chooses again; owner decision, 2026-10-12: a model added again becomes the selected model of no chat by itself
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · Only that added model goes

- **Given:** "Work AI" connects to provider P and has the added models M1 and M2. "Lab" is a custom model API with the provider ID "lab" and the added model M1.
- **When:** The user removes M1 from "Work AI" and saves.
- **Then:**
  - "Work AI" has the added model M2 only, and is still saved with its key and display name.
  - "Lab" still has the added model M1.
  - The user cannot choose M1 of "Work AI" for any chat. The user can still choose M1 of "Lab".
- **Check:** deterministic

### AC-2 · Nothing changes at the provider

- **Given:** The state of AC-1 before the removal. A test account with P records each request it receives.
- **When:** The user removes M1 from "Work AI" and saves.
- **Then:**
  - P receives no request.
- **Check:** deterministic

### AC-3 · A chat that selected the removed model

- **Given:** The state of AC-1 before the removal. Chat X has M1 of "Work AI" as its selected model. It has a conversation of four messages and a deck of five slides.
- **When:** The user removes M1 from "Work AI", saves and opens chat X.
- **Then:**
  - Chat X has no selected model. The system selected no other model.
  - The conversation of chat X shows the same four messages.
  - The five slides of chat X are the same as before.
- **Check:** deterministic

### AC-4 · Adding the model again

- **Given:** The state after AC-3.
- **When:** The user adds M1 to "Work AI" again, saves, and opens chat X.
- **Then:**
  - The user can choose M1 of "Work AI" for a chat.
  - Chat X has no selected model. M1 is not its selected model.
  - The conversation of chat X shows the same four messages, and its five slides are the same.
- **Check:** deterministic

## Notes

- A request in a chat whose selected model was removed is covered by FR-056.
- Deleting a whole provider configuration is covered by FR-063.
- Until 2026-10-12, AC-1 used two provider configurations for one provider. The owner decision of 2026-10-12 on provider IDs allows one for each provider ID.
