---
id: FR-088
title: "Use permitted public information during a request"
---

## Requirement

- **Statement:** When a request needs relevant public information and public research is permitted, the system searches through an outside research service that the Product Owner approved [NFR-007]. That permission allows the operation and approves no outside service. The system follows the user's limits on sources, names the outside sources it used, and claims no source was checked when it was not.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · Public research within permission

- **Given:** A chat permits public research. Public information is available. The user asks for a presentation about recent public developments and does not restrict the sources.
- **When:** The system prepares information for the request.
- **Then:**
  - The system obtains relevant public information when the request needs it.
  - It does not ask for approval again for a research operation already covered by the permission.
  - It uses relevant findings in the result.
- **Check:** judged

### AC-2 · Source restriction takes priority

- **Given:** A chat permits public research. The user asks to create a deck using only an attached report.
- **When:** The system prepares the outline.
- **Then:**
  - The system does not search for outside facts to add to the deck.
  - The outline contains no factual claim beyond the permitted material.
- **Check:** judged

### AC-3 · Outside source is identified

- **Given:** A request uses a public report obtained during research.
- **When:** The system presents the resulting outline or finished work.
- **Then:**
  - It names the public report as a source it used.
  - It does not describe unverified claims from the report as verified.
- **Check:** judged

### AC-4 · No approved research service

- **Given:** A chat permits public research. A request needs public information. No outside research service that the Product Owner approved is available.
- **When:** The system prepares information for the request.
- **Then:**
  - The system makes no connection to an outside research service.
  - It says which public information it could not obtain.
  - The request goes on or waits for the user, as FR-089 says for that gap.
- **Check:** deterministic

## Notes

- An operation that is not covered by permission requires approval under FR-076. This requirement gives no permission by itself.
- FR-090 protects private content during public research. NFR-007 governs outside connections.
- FR-089 sets what follows when the information is unavailable, including when the request goes on without it.
