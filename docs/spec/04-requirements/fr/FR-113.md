---
id: FR-113
title: "Resolve the generation format"
---

## Requirement

- **Statement:** After the user confirms the outline, the system proposes one available generation format for the deck. It uses the request, the material and the confirmed outline. With no named format and no special format need, it proposes the default generation format [BR-011]. A need gets a format that meets it, with the reason. A named available format is proposed as named. The system never puts another format in place of a named one without saying so.
- **Updated at:** 28-10-2026

## Acceptance conditions

### AC-1 · Default format with no special need

- **Given:** A confirmed outline of four planned slides. The request names no generation format and states no format need.
- **When:** The system proposes the generation format.
- **Then:**
  - The proposed format is the default generation format [BR-011].
  - The other available generation formats are shown as alternatives.
  - The system asks the user to confirm the generation format.
- **Check:** deterministic

### AC-2 · A stated need gets a justified proposal

- **Given:** A confirmed outline. The request says "I want to edit the slides as Markdown later". Marp is an available generation format.
- **When:** The system proposes the generation format.
- **Then:**
  - The proposed format is Marp, or another available format that the user edits as Markdown.
  - The reason names the need to edit the slides as Markdown.
  - The other available generation formats are shown as alternatives.
- **Check:** judged

### AC-3 · A named format is honored and still confirmed

- **Given:** A confirmed outline. The request says "make it in Slidev". Slidev is an available generation format.
- **When:** The system proposes the generation format.
- **Then:**
  - The proposed format is Slidev.
  - The system says that it follows the request.
  - The system asks the user to confirm the generation format.
  - The deck has no slide.
- **Check:** deterministic

### AC-4 · Several fitting formats ask nothing more

- **Given:** A confirmed outline. The request states a need that two available generation formats meet.
- **When:** The system proposes the generation format.
- **Then:**
  - The system proposes one of them and shows the other as an alternative.
  - The system asks no extra question only because two formats meet the need.
- **Check:** judged

### AC-5 · A named format that is not available is not replaced silently

- **Given:** A confirmed outline. The request names a generation format that the system cannot build in the current context.
- **When:** The system proposes the generation format.
- **Then:**
  - The system says that the named format is not available, and why.
  - The system shows the available generation formats as alternatives.
  - The system does not present another format as the named one.
  - The deck has no slide.
- **Check:** deterministic

## Notes

- Which generation formats are available is covered by FR-117. How the user reads and chooses among them is FR-114. The confirmation is FR-115.
