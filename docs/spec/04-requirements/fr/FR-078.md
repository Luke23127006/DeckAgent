id: FR-078
title: "Show the context usage of a chat"
---

## Requirement

- **Statement:** The user can see how much of the context of the selected model the conversation and the request in preparation of the chat use. The system says whether the number it shows is an estimate of DeckAgent or one the provider reported. The system invents no number it cannot compute, and never presents an estimate as a number the provider reported. Opening the context usage changes no conversation, no request text and no attachment (FR-038).

## Acceptance conditions

### AC-1 · The usage covers conversation and request in preparation

- **Given:** A chat with a conversation and a selected model whose context size is a value the system knows [BR-005]. The request area holds unsent request text and one ready attachment.
- **When:** The user opens the context usage of the chat.
- **Then:**
  - The response shows how much of the context of the selected model the conversation and the request in preparation use.
- **Check:** deterministic

### AC-2 · The kind of number is said

- **Given:** The state after AC-1.
- **When:** The user reads the usage shown.
- **Then:**
  - The response says whether the number is an estimate of DeckAgent or one the provider reported. Each number shown is labeled as one of the two.
- **Check:** deterministic

### AC-3 · No invented number

- **Given:** The state after AC-1.
- **When:** The user searches the response for a number the system cannot know.
- **Then:**
  - No number is presented as exact or as reported by the provider unless the provider reported it.
- **Check:** judged

## Notes

- Whether the provider reports a context usage for each of its models, and which numbers are exact, are open questions in the design backlog of the ideal spec. That question carries a quality-target marker [NFR-?] in its use case.
