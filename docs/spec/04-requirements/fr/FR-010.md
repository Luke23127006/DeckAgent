title: "Mark facts the material does not give"
---

## Requirement

- **Statement:** The outline can need a fact about the user's own subject that nothing the user gave provides. The system then writes a placeholder instead of inventing the fact [BR-?: content and figures added without a source]. It marks each such point and names each missing fact in the message with the outline.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-12: no invented fact about the user's own subject; general knowledge stays allowed
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · Missing figures become placeholders

- **Given:** A chat with no deck. The request is "a talk on our pilot results, with a slide on cost savings and the number of sites, from these notes". The notes describe the pilot. They give no cost figure and no number of sites. The system asked nothing about them.
- **When:** The system shows the outline proposal.
- **Then:**
  - The point on cost savings is marked as a placeholder.
  - The point on the number of sites is marked as a placeholder.
  - The proposal gives no figure for the cost savings.
  - The proposal gives no number of sites.
- **Check:** judged

### AC-2 · Each missing fact is named

- **Given:** The state of AC-1.
- **When:** The system shows the outline proposal.
- **Then:**
  - The message with the outline names the cost savings as missing.
  - The message names the number of sites as missing.
- **Check:** judged

### AC-3 · General knowledge is not a missing fact

- **Given:** A chat with no deck. The request is "a talk on our ward's hand hygiene pilot, from these notes". The notes describe the steps of the pilot. They give no compliance rate for the ward.
- **When:** The system shows the outline proposal, and it has a point on why hand hygiene prevents infections.
- **Then:**
  - That general point is not marked as a placeholder.
  - Any point on the ward's compliance rate is marked as a placeholder.
  - The proposal gives no compliance rate for the ward.
- **Check:** judged
