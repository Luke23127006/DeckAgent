id: FR-039
title: "Show what a model setup needs"
---

## Requirement

- **Statement:** The model setup shows the model that is set up, with its provider, or shows that none is set up. It shows the providers the user can add, and the models of a chosen provider [BR-005]. It says what that provider needs before its models can run [BR-006]. It says that the key comes from the user's own account with the provider. It says that each request run with the model goes to that provider.
- **Status:** confirmed
- **Source:** use case flow
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · No model set up yet

- **Given:** No model is set up.
- **When:** The user opens the model setup.
- **Then:**
  - The setup shows that no model is set up.
  - The setup shows each provider that the user can add [BR-005].
- **Check:** deterministic

### AC-2 · The model that is set up

- **Given:** Model M of provider P is set up.
- **When:** The user opens the model setup.
- **Then:**
  - The setup shows model M with provider P as set up.
- **Check:** deterministic

### AC-3 · Models and needs of a chosen provider

- **Given:** The state of AC-1.
- **When:** The user chooses provider P.
- **Then:**
  - The setup shows each model of P that the user can add [BR-005].
  - The setup shows what P needs before its models can run [BR-006].
- **Check:** deterministic

### AC-4 · Whose key, and where requests go

- **Given:** The state after AC-3.
- **When:** The user reads the setup for provider P.
- **Then:**
  - The setup says that the key comes from the user's own account with P.
  - The setup says that each request run with a model of P goes to P.
- **Check:** judged

## Notes

- No provider or model is named here. The offered providers and models are values of BR-005.
