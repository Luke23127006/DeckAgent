---
id: FR-095
title: "Preview design options before slide generation"
---

## Requirement

- **Statement:** When the user asks to see design options for the deck before any slide is built, the system shows representative design proposals for that deck. Each proposal follows the chosen design system, and a chosen visual style when one is chosen. The user can choose one proposal, and the system builds one deck from it. The proposals save no design system and no visual style.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · Proposals appear before any slide

- **Given:** The user confirmed an outline of four planned slides. The chat has no deck. The design system "Acme" is chosen.
- **When:** The user asks to see design options before the slides are built.
- **Then:**
  - The conversation shows representative design proposals for this deck.
  - Each proposal uses "Acme".
  - The deck canvas shows no slide.
- **Check:** deterministic

### AC-2 · One deck comes from the chosen proposal

- **Given:** The state of AC-1. The conversation shows proposal A and proposal B.
- **When:** The user chooses proposal B.
- **Then:**
  - The chat holds one deck.
  - Each slide of the deck follows proposal B.
  - The deck holds no slide made from proposal A.
  - The system saved no design system and no visual style from the proposals.
- **Check:** judged

### AC-3 · Design options are not a mandatory step

- **Given:** The user confirmed an outline of four planned slides. The user asked for no design options.
- **When:** The system has built the slides.
- **Then:**
  - The system showed no design proposal before the slides.
  - The deck has four slides.
  - The request finished.
- **Check:** deterministic

### AC-4 · A chosen visual style shapes each proposal

- **Given:** The design system "Acme" and the visual style "Editorial" are chosen. The user asks to see design options.
- **When:** The system shows the proposals.
- **Then:**
  - Each proposal follows the rules of "Editorial".
  - Each proposal follows the rules of "Acme".
- **Check:** judged
