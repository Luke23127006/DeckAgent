---
id: FR-006
title: "Refuse to confirm an empty current outline"
---

## Requirement

- **Statement:** The system does not confirm an empty current outline and builds no slide from it. To a clear confirmation, it says briefly that the outline needs content and suggests asking for a revision. It reports no failure to build slides and drafts no new outline by itself.
- **Status:** confirmed
- **Source:** use case flow
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · No confirmation offered, no error message

- **Given:** The current outline had four planned slides. The user sent "remove every slide from the outline". The system showed a new outline response with no planned slide.
- **When:** The system has shown that response.
- **Then:**
  - The system does not offer to confirm the outline.
  - The system shows no error message.
  - The empty outline is the latest outline response.
  - No outline proposal is confirmed.
- **Check:** deterministic

### AC-2 · Typed confirmation confirms nothing

- **Given:** The state of AC-1.
- **When:** The user sends "Confirm the outline".
- **Then:**
  - No outline proposal is confirmed.
  - The deck has no slide.
  - The system shows no deck canvas.
  - The system reports no failure to build slides.
  - Every outline response is the same as before the message.
  - No new outline proposal appears.
- **Check:** deterministic

### AC-3 · No planned slide has a title

- **Given:** A revision left a current outline of three planned slides. No slide title has text, or a title has only spaces. Some points still have text.
- **When:** The user sends "Confirm the outline".
- **Then:**
  - No outline proposal is confirmed.
  - The deck has no slide.
- **Check:** deterministic
- **Status:** proposed default
- **Source:** proposed
- **Why:** The use case does not define "empty". This default makes the boundary testable: an outline counts as empty when no planned slide has a title with text, and a title of only spaces has no text. Trade-off: an outline with points but no titles cannot be confirmed, so the user asks for titles first.

### AC-4 · Reply explains and points to a revision

- **Given:** The state of AC-1.
- **When:** The user sends "Confirm the outline".
- **Then:**
  - The reply says briefly that the outline needs content before the slides are built.
  - The reply suggests asking for a revision of the outline.
  - The reply does not present an error or a failed build.
- **Check:** judged
