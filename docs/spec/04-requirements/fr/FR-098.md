---
id: FR-098
title: "Remove a design system"
---

## Requirement

- **Statement:** The system removes a design system the user created when the user asks. It rejects the removal of the default design system [BR-003]. Removing a design system changes no deck, no visual style and no other design system.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · A user-created design system is removed

- **Given:** "Acme" and "Client" are saved. A deck was built with "Acme".
- **When:** The user removes "Acme".
- **Then:**
  - "Acme" is no longer among the design systems the user can choose.
  - Every slide of the deck is as it was.
  - "Client" holds the same rules as before.
- **Check:** deterministic

### AC-2 · The default design system stays

- **Given:** The default design system is offered beside "Acme".
- **When:** The user tries to remove the default design system.
- **Then:**
  - The system rejects the removal.
  - The default design system remains among those the user can choose.
  - No deck changed.
- **Check:** deterministic

### AC-3 · No visual style changes

- **Given:** The custom visual style "Report" is saved. "Acme" is saved.
- **When:** The user removes "Acme".
- **Then:**
  - "Report" holds the same rules as before.
  - "Report" remains among the visual styles the user can choose.
- **Check:** deterministic
