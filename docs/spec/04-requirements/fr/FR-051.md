---
id: FR-051
title: "Open a chat that has no slides yet"
---

## Requirement

- **Statement:** An opened chat can have no slides yet. The system then shows its conversation in order and says that the chat has no slides yet. An outline that waits for confirmation still waits. With a confirmed outline, a new request builds on it and shows no second outline. With no outline, the user can send a new request in the chat.
- **Status:** confirmed
- **Source:** use case flow
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · An outline still waits for confirmation

- **Given:** Earlier chat X holds a request and outline proposal B, which the user has not confirmed. The deck of chat X has no slide.
- **When:** The user opens chat X.
- **Then:**
  - The conversation shows the request and proposal B, in order.
  - Proposal B is not confirmed. It is the current outline.
  - The system offers to confirm proposal B.
  - The deck has no slide.
- **Check:** deterministic

### AC-2 · The user is told there are no slides

- **Given:** The state after AC-1.
- **When:** The user reads the chat.
- **Then:**
  - The system says that chat X has no slides yet.
- **Check:** judged

### AC-3 · Confirmed outline and no slide

- **Given:** Earlier chat Y holds a confirmed outline of four planned slides. DeckAgent was closed before any slide was finished. The deck of chat Y has no slide.
- **When:** The user opens chat Y and sends "build the slides".
- **Then:**
  - No outline proposal appears.
  - The confirmed outline is the same as at the confirmation.
  - The system builds slides for the request.
- **Check:** deterministic

### AC-4 · No outline

- **Given:** Earlier chat W holds only the request "a talk on our pilot results". It ended before any outline was shown.
- **When:** The user opens chat W and sends "a talk on our pilot results".
- **Then:**
  - The conversation shows the new request as a new user's message.
  - The earlier request shows once, unchanged.
  - The system works on the new request.
- **Check:** deterministic

## Not specified

- Whether a new request gets an outline proposal first, in a chat whose earlier request ended before any outline. Pending owner decision.

## Notes

- Opening the chat itself is covered by FR-049. A chat whose last request did not finish is covered by FR-052.
