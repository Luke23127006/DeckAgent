title: "Ask before drafting the first outline"

## Requirement

- **Statement:** Before the first outline, the system asks for the topic when the request and the material leave it unknown. It also asks about an open point that would change the outline a lot [BR-?: when the system asks before the outline]. It asks nothing they already answer, and it offers answers to choose from. The user can also answer in their own words, or skip.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-11: before the outline, the system asks only the questions it needs
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · Unknown topic: question, no outline

- **Given:** A chat with no deck. The request is "make me a presentation", with no material.
- **When:** The system responds.
- **Then:**
  - No outline proposal appears.
  - The system asks a question in the conversation.
  - The deck has no slide.
- **Check:** deterministic

### AC-2 · Unknown topic after a file with nothing usable

- **Given:** A chat with no deck. The request is "make slides from this", with the accepted attachment "scan.pdf". Every page of "scan.pdf" is blank.
- **When:** The system responds.
- **Then:**
  - No outline proposal appears.
  - The system asks a question in the conversation.
- **Check:** deterministic

### AC-3 · The question asks for the topic

- **Given:** The state of AC-1 or of AC-2.
- **When:** The system asks its question.
- **Then:**
  - The question asks what the presentation is about.
- **Check:** judged

### AC-4 · Clear request gets no needless question

- **Given:** A chat with no deck. The request is "a ten-minute talk to convince our hospital board to extend the pilot, from these notes". The notes describe the pilot and its results.
- **When:** The system responds.
- **Then:**
  - The system asks no question only to explore a topic that the request and the notes already make clear.
  - Each question it asks, when it asks one, is about an open point that would change the outline a lot.
  - Without such an open point, the system drafts the outline proposal without a question.
- **Check:** judged

### AC-5 · Nothing already given is asked

- **Given:** A chat with no deck. The request is "a talk for hospital board members on our pilot", with no material.
- **When:** The system asks its questions before the outline.
- **Then:**
  - No question asks what the talk is about.
  - No question asks who the audience is.
- **Check:** judged

### AC-6 · Offered answers, own answer and skip

- **Given:** The system asked a question before the outline and waits for the answer.
- **When:** The user reads the question.
- **Then:**
  - The system offers answers to choose from as suggested options.
  - The user can answer in their own words instead.
  - The user can skip the question.
- **Check:** deterministic

### AC-7 · Skipped question leads to the outline

- **Given:** A chat with no deck. The request is "a talk on our pilot". The system asked who the audience is, and asked nothing else.
- **When:** The user skips the question.
- **Then:**
  - The conversation shows an outline proposal.
  - The system does not ask about the audience again.
- **Check:** deterministic

## Not specified

- Which open points other than the topic change the outline enough for the system to ask. Pending owner decision.
- What the system does when the user skips a question about the topic. Pending owner decision.
