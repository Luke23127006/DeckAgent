---
id: FR-072
title: "Keep a default workspace from the first start"
---

## Requirement

- **Statement:** The first start on the computer offers the default workspace, before the user has chosen any folder, and the user can work in it without choosing a folder. The default workspace has no project folder and cannot be removed. The work DeckAgent saves for its chats stays available, and each of those chats reopens with its conversation and its deck without a folder. Chats made before workspaces were set up behave like chats of a workspace that stays reachable (FR-073).
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · The first start offers the default workspace

- **Given:** DeckAgent runs on the computer for the first time. No workspace was ever set up and no folder was chosen.
- **When:** The user starts to work.
- **Then:**
  - The default workspace is the workspace in use, and the user can start a new chat in it (FR-053).
  - No folder is asked for.
- **Check:** deterministic

### AC-2 · The default workspace cannot be removed

- **Given:** The state after AC-1. Earlier chats exist in the default workspace.
- **When:** The user looks for the default workspace among the workspaces that are set up, to remove it.
- **Then:**
  - The default workspace is not offered for removal. It stays the workspace that holds its chats (FR-048).
- **Check:** deterministic

### AC-3 · The work of the default workspace needs no folder

- **Given:** A chat in the default workspace holds a conversation and a deck of five slides. DeckAgent was then closed and opened again.
- **When:** The user opens that chat.
- **Then:**
  - The conversation shows the same messages as before DeckAgent was closed.
  - The deck canvas shows the same five slides.
  - The system asked for no folder at any point.
- **Check:** deterministic

## Notes

- Which other workspaces are set up by default, if any, is an open question in the design backlog of the ideal spec.
- That a chat of a workspace with a project folder still opens when that folder cannot be read is FR-049 and FR-074.
