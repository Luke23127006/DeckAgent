---
id: FR-112
title: "Protect built-in design systems"
---

## Requirement

- **Statement:** A built-in design system keeps the original definition DeckAgent gave it, and the user cannot change or remove that definition. The user can choose it for a deck, and can make a custom design system from it by an explicit choice. An attempt to change or remove the original offers that choice and creates no copy by itself.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · A built-in design system cannot be edited

- **Given:** DeckAgent provides a built-in design system with its original brand colours and fonts.
- **When:** The user tries to change a brand colour of that built-in design system.
- **Then:**
  - The built-in design system holds the same rules as before the attempt.
  - The system offers to make a custom design system from it.
  - No custom design system is saved.
- **Check:** deterministic

### AC-2 · A built-in design system cannot be removed

- **Given:** DeckAgent provides a built-in design system with its original rules.
- **When:** The user tries to remove the built-in design system.
- **Then:**
  - The system refuses the removal.
  - The built-in design system remains among the design systems the user can choose.
  - The built-in design system holds the same rules as before the attempt.
- **Check:** deterministic

### AC-3 · A custom copy needs an explicit choice

- **Given:** A built-in design system holds its original rules. The user tried to change it, and the system offered a custom copy.
- **When:** The user chooses whether to make the copy.
- **Then:**
  - Nothing is saved before the user chooses.
  - A choice to make the copy gives an unsaved custom design system proposal.
  - A choice to make no copy saves no custom design system.
  - The built-in design system holds the same rules as before the attempt.
- **Check:** deterministic

## Notes

- Which built-in design systems the product offers, and which brand attributes each one holds, are questions in the design backlog of the ideal spec.
