---
id: FR-025
title: "Keep finished slides when the work on slides ends early"
---

## Requirement

- **Statement:** When work on slides stops or fails, the system keeps each slide it finished before the work ended. It shows no unfinished slide and no unfinished change. A slide it did not finish changing keeps its last finished state. Every other slide and the confirmed outline stay as they were. The system says that the finished slides can disagree with each other. It does not change a finished slide to make them agree.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-11: a stop or a failure keeps finished slides only; an unfinished change never replaces the last finished state of a slide; the first draft does not count as finished; owner decision, 2026-10-13: the deck can disagree with itself after a stop or a failure; the system says so without claiming that it checked, and does not rewrite finished slides to make them agree
- **Updated at:** 13-10-2026

## Acceptance conditions

### AC-1 · First draft keeps its finished slides

- **Given:** The user confirmed an outline of four planned slides. The system finished slides 1 and 2 and builds slide 3.
- **When:** The work ends, in two separate runs. The user stops the request. The model provider returns an error.
- **Then:**
  - In each run, the deck canvas shows slides 1 and 2, the same as before the work ended.
  - In each run, the deck canvas shows no unfinished slide.
  - In each run, the confirmed outline is in the conversation, the same as at the confirmation.
  - In each run, no new outline proposal appears.
- **Check:** deterministic

### AC-2 · No empty slide without a reason

- **Given:** The state after AC-1.
- **When:** The user looks through the deck canvas.
- **Then:**
  - The deck canvas shows no empty slide without saying why it is empty.
- **Check:** judged

### AC-3 · Unfinished draft is not called finished

- **Given:** The state after AC-1.
- **When:** The user reads the conversation.
- **Then:**
  - The conversation does not say that the draft is ready or complete.
- **Check:** judged

### AC-4 · Unfinished change does not replace a slide

- **Given:** A deck of five slides. The user sent "make slides 2, 3 and 4 shorter". The system finished changing slide 2 and is changing slide 3.
- **When:** The work ends, in two separate runs. The user stops the request. The model provider returns an error.
- **Then:**
  - In each run, slide 2 is the same as when its change was finished.
  - In each run, slides 3 and 4 are the same as before the request.
  - In each run, slides 1 and 5 are the same as before the request.
  - In each run, the deck has five slides.
- **Check:** deterministic

### AC-5 · Unfinished new slide is not shown

- **Given:** A deck of five slides. The user sent "add a slide on costs after slide 2, and a slide on next steps at the end". The system finished the slide on costs and builds the slide on next steps.
- **When:** The user stops the request.
- **Then:**
  - The deck has six slides.
  - Slide 3 is the finished slide on costs.
  - The other five slides are the same as before the request, in the same order.
- **Check:** deterministic

### AC-6 · The user is told the slides can disagree

- **Given:** The states after AC-1 and after AC-4.
- **When:** The user reads the conversation.
- **Then:**
  - The conversation says that the finished slides can disagree with each other.
  - It does not say that the system checked the slides against each other.
  - It does not say that the system found a disagreement it did not find.
- **Check:** judged

## Notes

- A slide counts as finished when it was finished before the stop or the failure took effect. FR-018 and FR-019 cover the stop and the failure themselves.
- The number of finished or changed slides that the system reports is covered by FR-026.
- Preservation is checked by comparing the deck before and after, not by reading a message of the system.
- AC-1 and AC-4 also check that the system does not change a finished slide to make the deck agree.
- Until 2026-10-13, what the system says about finished slides that disagree was open. The owner decision of 2026-10-13 settled it.
