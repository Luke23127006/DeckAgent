id: FR-041
title: "Save a complete model setup"
---

## Requirement

- **Statement:** With no model set up, the user saves a setup. It gives a provider, one of its models and what the provider needs [BR-006]. The system then sets up that model as the one working model, with its provider and the user's key. It says that the model is set up.
- **Status:** confirmed
- **Source:** use case flow, and owner decision, 2026-10-11: the user sets up a model with their own key inside DeckAgent, without a developer's help; owner decision, 2026-10-12: V1 has one working model
- **Updated at:** 12-10-2026

## Acceptance conditions

### AC-1 · The model is set up

- **Given:** No model is set up. Provider P needs a key [BR-006].
- **When:** The user chooses provider P and its model M, gives the key K1 and saves.
- **Then:**
  - The model setup shows model M with provider P as set up.
- **Check:** deterministic

### AC-2 · The user is told

- **Given:** The state of AC-1.
- **When:** The user saves.
- **Then:**
  - The system says that model M is set up.
- **Check:** judged

## Not specified

- Whether the system checks the key with the provider when the user saves. Pending owner decision.

## Notes

- Which model runs later requests is covered by FR-042. A setup that lacks something is covered by FR-045.
- V1 has one working model. Several saved models, and replacing the model with another one, are not part of V1. Replacing the key of its provider is covered by FR-043.
