---
id: FR-094
title: "Choose a visual style for slide generation"
---

## Requirement

- **Statement:** The user can choose a built-in or a custom visual style for a deck. When one is chosen, its rules guide the presentation design of the slides. When the user chooses none, the system chooses a suitable presentation design that follows the applicable design system and the content and purpose of each slide. The product sets no default visual style.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · A chosen built-in visual style guides the slides

- **Given:** The built-in visual style "Editorial" holds layout, density and heading rules. The design system "Acme" is chosen. A chat has no deck. The user prepared a request for a deck of four slides.
- **When:** The user chooses "Editorial" and the system builds the slides.
- **Then:**
  - Each slide follows the layout, density and heading rules of "Editorial".
  - Each slide follows the brand rules of "Acme".
  - "Editorial" and "Acme" hold the same rules as before the request.
- **Check:** judged

### AC-2 · No visual style chosen still builds every slide

- **Given:** The user chose no visual style. "Acme" is chosen. The user confirmed an outline of four planned slides.
- **When:** The system has built the slides.
- **Then:**
  - The deck has four slides.
  - The system shows no visual style as chosen for the deck.
  - The system saved no visual style.
- **Check:** deterministic

### AC-3 · The chosen design suits the content without a style

- **Given:** The state of AC-2. The four planned slides differ in kind: one gives a figure, one gives a list of steps, one gives a quotation, and one gives a closing request.
- **When:** The user reads the finished slides.
- **Then:**
  - Each slide has a readable layout that fits its content.
  - Each slide follows the brand rules of "Acme".
  - The system did not require the user to approve the design before it finished.
- **Check:** judged

### AC-4 · A custom visual style can be chosen

- **Given:** The user saved a custom visual style "Report". A chat has no deck.
- **When:** The user chooses "Report" and the system builds the slides.
- **Then:**
  - Each slide follows the rules of "Report".
  - "Report" holds the same rules as before the request.
- **Check:** judged
