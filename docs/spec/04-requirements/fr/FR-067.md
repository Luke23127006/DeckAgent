---
id: FR-067
title: "Say when material is used only in part"
---

## Requirement

- **Statement:** When the system uses only part of the material of a request, it says so in the conversation. This holds when part of a file cannot be read. It also holds when the conversation and the material are more than the work takes at once. The system names the material and the part it did not use, when it knows them. It never says that it used content it did not use. A missing part sometimes changes the result a lot. The system then asks the user to give that part again, or to change the request.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · File read in part

- **Given:** A chat with no deck. The request "a talk from my report" has the attachment "report.pdf" of 20 pages. In this test, pages 12 to 20 cannot be read. The pilot results appear only on those pages.
- **When:** The system shows the outline proposal.
- **Then:**
  - The message with the outline names "report.pdf".
  - The message says that part of the file was not used.
  - The message does not say that the whole file was used.
- **Check:** judged

### AC-2 · Earlier material more than the work takes

- **Given:** A chat with a deck of five slides. In this test, the conversation and the attachments of the chat are more than the work takes at once.
- **When:** The user sends "add a slide on the cost results after slide 4", and the system finishes the work.
- **Then:**
  - The conversation says that the work did not use all the earlier material.
  - The conversation does not say that all the material was used.
- **Check:** judged

### AC-3 · Missing part that changes the result

- **Given:** A chat with no deck. The request "a talk on chapter 3 of my book" has the attachment "book.pdf". In this test, chapter 3 cannot be read.
- **When:** The system responds to the request.
- **Then:**
  - No outline proposal appears.
  - The system waits for the user's answer within the request.
- **Check:** deterministic

### AC-4 · The question asks for the missing part

- **Given:** The state after AC-3.
- **When:** The user reads the question.
- **Then:**
  - The question says that chapter 3 was not used.
  - It asks the user to give chapter 3 again or to change the request.
- **Check:** judged

## Notes

- A file with nothing usable at all is covered by FR-009.
- Material that stops being readable while the request runs is FR-086. A file the request already read stays material the request obtained, and the system uses no other file in its place.
- No size of what the work takes at once is promised. It depends on the model and on the architecture.
- The wait for the answer is covered by FR-020.
