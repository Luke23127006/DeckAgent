---
id: FR-122
title: "Report failed deck export and start a fresh attempt"
---

## Requirement

- **Statement:** A deck export succeeds only when its file holds every page or file of the chosen snapshot. Otherwise the system gives no file, says that the export failed, and never calls an incomplete file a success. A failure or a cancellation changes no deck and replaces no existing file. A new attempt uses the stable deck state at the start of that attempt. The system changes no output kind, destination or setting by itself. An export calls no model and starts, stops or resumes no request.
- **Updated at:** 28-10-2026

## Acceptance conditions

### AC-1 · An incomplete PDF is a failure

- **Given:** A deck of six finished slides. The PDF export fails after four pages.
- **When:** The export ends.
- **Then:**
  - No PDF file is given.
  - The system says that the export failed.
  - The system does not say that four pages were exported.
- **Check:** deterministic

### AC-2 · An incomplete archive is a failure

- **Given:** A deck of six finished slides. A PNG export fails after four images.
- **When:** The export ends.
- **Then:**
  - No archive is given.
  - The system says that the export failed.
- **Check:** deterministic

### AC-3 · Failure keeps the deck and the files of the user

- **Given:** The destination holds "notes.txt". A deck export to that destination fails, or the user cancels it.
- **When:** The export ends.
- **Then:**
  - "notes.txt" is the same as before.
  - The deck is the same as before.
  - The user can start a new export attempt.
- **Check:** deterministic

### AC-4 · A new attempt uses the current deck state

- **Given:** A PDF export failed. Then the user changed slide 2 with a follow-up request that finished.
- **When:** The user starts a new export attempt.
- **Then:**
  - The PDF holds the changed slide 2.
  - The PDF uses no snapshot of the failed attempt.
- **Check:** deterministic

### AC-5 · No silent change of choices

- **Given:** A PDF export to the folder "Deliver" failed.
- **When:** The user starts a new export attempt.
- **Then:**
  - The output kind and the destination are the ones the user chose for this attempt.
  - The system does not choose another output kind or destination by itself.
- **Check:** deterministic

### AC-6 · Export starts no model work

- **Given:** A deck of four finished slides and a selected generation format.
- **When:** The user exports the deck, in a run that succeeds and a run that fails.
- **Then:**
  - In each run, no model is called.
  - In each run, no request starts, stops or resumes.
  - In each run, the slides and the generation format of the deck are the same as before.
- **Check:** deterministic
