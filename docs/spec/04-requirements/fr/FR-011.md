---
id: FR-011
title: "Disclose material that does not agree with itself"
---

## Requirement

- **Statement:** When two parts of the user's material disagree on a point the work needs, the system names both parts and where each one is. It tells the user before the outline when the disagreement materially affects the planned content. Otherwise it discloses the disagreement with the outline where relevant. It never silently presents either part as settled.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · Disagreement is named

- **Given:** A chat with no deck. The request is "a talk on our survey, from this report". The text of the report says that satisfaction rose by 12%. The results table of the report says 15%.
- **When:** The system drafts the outline.
- **Then:**
  - The system tells the user that the report disagrees with itself on the rise in satisfaction.
  - It gives both figures, 12% and 15%.
- **Check:** judged

### AC-2 · Each part is located in plain words

- **Given:** The state of AC-1.
- **When:** The system tells the user about the disagreement.
- **Then:**
  - It says where each figure is, in words the user can follow, such as "the text" and "the results table".
- **Check:** judged

### AC-3 · No silent choice

- **Given:** The state of AC-1.
- **When:** The system shows the outline proposal.
- **Then:**
  - The proposal never presents 12% or 15% as the settled figure without telling the user that the report disagrees.
- **Check:** judged

### AC-4 · An important disagreement is disclosed before the outline

- **Given:** A request asks for a deck about survey results. The summary says satisfaction rose by 12%, while the results table says 15%. The figure is central to the requested conclusion.
- **When:** The system prepares the outline.
- **Then:**
  - Before showing an outline, the system names both figures and their locations.
  - It does not claim either figure is correct.
- **Check:** judged

## Notes

- The disputed point stays open, and no part is called correct. FR-037 covers it. This requirement covers only the disclosure.
