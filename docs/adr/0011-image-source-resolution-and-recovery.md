# Resolve image origins and recover failed selections within one review request

The [reviewed-image decision](0010-reviewed-public-images.md) requires an explicit model choice before an image is prepared. Top-level Tavily image results can contain only a CDN URL and description. Pairing every such image with the first text results loses its origin and cannot establish a reuse licence. Source resolution therefore distinguishes publisher identity, candidate page hints, licence evidence and download failures.

Commons upload and thumbnail paths identify a file whose metadata is checked through the Commons API. Thumbnail size differences cannot change file identity. A different image cannot borrow a Commons page's licence. Other returned pages remain hints until matching image-specific metadata establishes a credit; at most three hints are checked, with a request-local cache of at most 25 source pages. HTTP denial, network failure, unsupported format, size limits, unsupported licences and missing evidence retain separate codes and bounded attempt records.

Pexels stock photos identified by the official `images.pexels.com/photos/{id}/...` path are accepted under the [Pexels License](https://www.pexels.com/license/) and [content terms](https://www.pexels.com/terms-of-service/), as illustrations within a presentation. The official policy permits presentation use subject to its restrictions; it does not make every use unrestricted. This is a scoped extension of the [public-image licence rule](../spec/04-business-rules/BR-014.md). Pexels remains a distinct licence value, never CC0 or CC BY. Its credit records `pexels-cdn` evidence, the policy link and a photo-page URL derived from the stock ID. The application does not claim to have read that page or identified its author. Sponsored images, other hosts and non-photo paths receive no platform licence from this rule. The downloaded variant uses the documented [large2x dimensions](https://www.pexels.com/api/documentation/) and its exact URL is retained with the credit. This keeps large originals below existing parser pixel limits without weakening those limits. Download and byte checks still apply.

The model can supply one preferred candidate and two ranked alternatives with reasons. The Host tries only those choices, with four selection attempts and two searches per position. The existing five-search request budget and free-only Tavily checks remain in force. If a successful model run leaves required images with useful repairs, the Host permits one additional run using the same admitted provider/model and only the image tools. Brief, Outline, source grants and visual choices remain frozen. No further repair run is scheduled. Stop prevents the staged proposal from committing; exhausted or failed repair leaves explicit unresolved positions instead of an endless request.

Prepared assets retain bounded attempt records in their immutable Outline. The interface shows the last failure and source-check history, including HTTP status when available. Required unresolved positions disable confirmation and name the remaining image count. Preview and generation continue to consume local bytes only.

Deck schema 10 marks the extended licence and diagnostic contract so older readers refuse it. Existing rows, files, confirmations and visual snapshots are preserved. Policy version `web-images-v2` invalidates query-context reuse for new reviews, while confirmed decks retain their prepared assets. Deploy Host producers, browser decoders and licence consumers together. Fixture coverage includes top-level CDN results, blocked sources, ranked alternatives, bounded MCP recovery, Stop and publication with Pexels credits; live search/model relevance remains separate.

## Resume image work across requests

A subsequent review request reconstructs its working Brief, Outline and image positions from the current saved proposal. Reconstruction reads checked local assets and makes no search request. The model receives current need IDs, prepared status and fresh bounded budgets; candidate IDs from earlier requests are not retained. A request to continue image work can call image tools directly without submitting unchanged Brief and Outline payloads. No user phrase is a trigger in Host code. Questions, including questions sent through the default revision action, create no version and schedule no recovery unless the model actually performs image work.

An admitted provider change applies to subsequent searches. Rebinding the exact saved context to that provider preserves prepared bytes, credit and original search provenance. A changed query, role, slide text or explicit replacement requires review. Image work saves a new immutable proposal with optimistic version checks; Stop and rejected stale requests keep the prior proposal. A stale need ID returns the current positions. Unrepaired context or argument errors finish as failures, rather than appearing as successful searches with no results. The [public-image reference](../development/portable-slide-content.md#public-image-preparation) owns the executable behavior and limits.
