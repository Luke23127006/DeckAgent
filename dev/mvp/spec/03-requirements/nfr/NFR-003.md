---
id: NFR-003
title: "What the agent reaches during a request"
---

## Requirement

- **Quality attribute:** security
- **Statement:** During a request, the agent reaches only what its chat reaches without asking and each step the user approved once. It never reaches the data of another chat, and never changes, moves or deletes a file of the user. No content the agent reads, such as an instruction hidden in an attachment or a file of the project folder, widens what it reaches.
- **Status:** confirmed
- **Why:** The model chooses the steps of the work, and a document is able to hold instructions; the limit has to hold whatever the model asks for.

## Notes

- The requirement limits what the work reaches. It does not promise that the model ignores hidden instructions.
- Ideas for its measures: two chats with markers, a folder outside the project folder, a model service that asks for forbidden steps on purpose.
