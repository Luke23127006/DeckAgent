---
id: NFR-004
title: "Shown content reaches nothing"
---

## Requirement

- **Quality attribute:** security
- **Statement:** Content that the model writes, or that comes from material, never runs with access to the data of DeckAgent, a key or the network, wherever the system shows it. Code that the trusted parts of DeckAgent run, such as the template of a deck, is not such content.
- **Status:** confirmed
- **Why:** Shown content that ran with that access would reach what the agent is not allowed to reach.

## Notes

- A deck source in a web-based format is allowed to hold code that runs for the slides; the requirement limits what that code reaches, not whether it runs.
- Loading a font, an image or another resource a slide needs is not such access; where those loads go is a matter of where user content goes, not of this requirement.
