title: "Where user content goes"
---

## Requirement

- **Quality attribute:** privacy
- **Statement:** **User content leaves the computer only** in the requests DeckAgent sends to the **provider of the selected model**, or to an **outside service the user set up**. **Each other outside connection carries no user content**. The **project documentation lists each kind of outside connection** with its scope and purpose.
- **Status:** confirmed
