title: "Keep a default workspace from the first start"
---

## Requirement

- **Statement:** **From the first start** on the computer, the system has a **default workspace with no project folder**, and **makes it the workspace in use** until the user chooses another one. The user **works in it without choosing a folder**. The system **never removes the default workspace**, and its chats **keep their conversations and decks without any folder**.
- **Status:** confirmed
