## Requirement

- **Statement:** With each outline proposal, the system **offers suggested revisions** that **fit the content of that outline**. **Choosing one asks for that revision**, with the **same result as the same revision written by the user**. The user is allowed to **write a revision in their own words** instead.
- **Status:** confirmed
- **Why:** **Napkin AI offers revisions written for each outline** (`dev/mvp/research/evidence/napkin-ai/napkin-ai-deck-generation-behavior.md`).
