---

## Requirement

- **Statement:** When the first draft is done, the system shows a closing message. The message tells what each slide holds, which assumptions were used, which text is placeholder and, for each slide, which content came from the model's general knowledge and which from public research. It never says that the system checked a figure or a claim that it did not check.
- **Status:** confirmed
