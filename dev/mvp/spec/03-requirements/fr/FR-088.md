## Requirement

- **Statement:** When the user chose public research as a source, the system searches through an outside service for research that the user set up [NFR-007]. It follows the user's limits on sources and names the outside sources it used. It never says that a source was checked when it was not.
- **Status:** confirmed
- **Why:** Teacher feedback of 23-10-2026: web search is one of the sources the user chooses.
