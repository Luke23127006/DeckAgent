## Requirement

- **Statement:** While the system works on a request, keeps the work of a chat or shows a deck, it creates, changes, moves and deletes no file in the project folder, a hidden file included. A file the user gave as an attachment stays as the user gave it. A file appears in the project folder only through an export the user chooses.
- **Status:** confirmed

## Notes

- Where the deck source and the rest of the work of a chat are kept: [DEC-006](../../../decisions/DEC-006-where-chat-work-is-kept.md) (open).
- Export, the way a file of the deck reaches a folder the user chooses, is in the backlog (UC-004, FR-085).
