title: "What the agent of a chat reaches without asking"
---

## Requirement

- **Statement:** **Without asking**, the agent of a chat **reads the files of the project folder** of its workspace, **also those no request names**, the **attachments of the chat** and the **work DeckAgent keeps for the chat**, **uses the outside services the user set up**, and **writes only the work of the chat**. **Every other step**, such as reading outside the project folder or writing outside the work of the chat, **needs the user's approval**; a **chat of the default workspace** and an **ungrouped chat** have **no project folder**, so **reading any folder needs one**. **No approval** lets the agent **reach the data of another chat** or **change, move or delete a file of the user**, and **no content** of a request, an attachment or a file **widens what the agent reaches**.
- **Status:** confirmed
- **Why:** A **fixed reach set by code**, with **no level of permission for the user to choose**; the **project folder is the place the user chose** for the work.

## Notes

- **Reading a file of the project folder** **sends its content to the provider** of the selected model [NFR-007]; the **user chose that folder** for the work.
- A **chat of a removed workspace becomes an ungrouped chat** (FR-073).
- **How the reach is set in the runtime**, for example through the permissions of OpenCode, is **runtime research of the first build**: [dev/mvp/research/agent-permissions.md](../../../research/agent-permissions.md).
