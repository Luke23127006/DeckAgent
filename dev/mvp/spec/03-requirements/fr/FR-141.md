id: FR-141
title: "Rename a workspace"
---

## Requirement

- **Statement:** When the user **gives a workspace a new name**, the system **gives the workspace that name**, the **default workspace included**. **Renaming keeps the project folder and the chats** of the workspace, **changes no folder and no file** of the user, and **stops no request**. **Two workspaces are allowed to have the same name**. The system **drops the whitespace at both ends** of a new name [BR-020]. The system **keeps the name in NFC form** [BR-020]. A **name the system refuses** [BR-020] **changes nothing**: the workspace **keeps its name**, and the system **says why** the name is refused.
- **Status:** confirmed
