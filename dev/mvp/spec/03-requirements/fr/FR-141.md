title: "Rename a workspace"
---

## Requirement

- **Statement:** When the user **gives a workspace a new name**, the system **gives the workspace that name**, the **default workspace included**. **Renaming keeps the project folder and the chats** of the workspace, **changes no folder and no file** of the user, and **stops no request**. **Two workspaces are allowed to have the same name**.
- **Status:** confirmed

## Undecided

- **Which names the system refuses**, such as a name with no character. Pending decision.
