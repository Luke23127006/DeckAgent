---
id: FR-076
title: "Ask before a step beyond what the agent reaches"
---

## Requirement

- **Statement:** When a step of the work of a request goes beyond what the agent of the chat reaches without asking, the system names the step, what it touches and why, and asks the user to allow it once or to refuse it; the request stays active while it waits, and the system does nothing past the step. An allowed step is done once, and a later step of the same kind is asked for again. A refused step is not done and not asked for again within the request: the system does the rest of the work within its reach, and the closing message names what it did not do because of the refusal.
- **Status:** confirmed
- **Why:** Two answers only, so no permission lasts and nothing needs taking back; a refusal does not throw away the rest of the work.

## Notes

- A request that waits for an approval is not a question: it stays active, the status message says what it waits on, and the user is allowed to stop it (FR-014, FR-018). The system reports no answer the user did not give.
- No permission lasts beyond the step it was given for. A clarifying question of the system is not an approval and allows nothing.
