---
id: FR-019
title: "Report a request that does not finish"
---

## Requirement

- **Statement:** When the work on a request does not finish, the system ends it and says that it did not finish, and why when it knows, such as an unreachable provider, a refused key or model, or a reached usage limit. It keeps the request, its activities and the finished work; an unfinished result never replaces the last finished one and is never offered for the user to confirm. It starts no work again by itself, keeps every provider and model setting, and selects no other model.
- **Status:** confirmed

## Notes

- A request that is active when DeckAgent stops does not finish. When DeckAgent starts again, it shows that request as not finished and resumes nothing (UC-003 A11).
- An unfinished outline is an unfinished result.
