## Requirement

- **Statement:** When asked whether the deck agrees with itself or with the user's material, the system names each pair of points that disagree, where each one is and what each one says. It says which one is right only when the user's material settles it. It says that the check covers only what it found, and changes no slide.
- **Status:** confirmed
