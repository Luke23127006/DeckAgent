## Requirement

- **Statement:** Changing or removing a custom design system changes no deck. Each deck that used it keeps its theme, and is shown and changed as before, also when the design system no longer exists. A deck takes the changed design system only when a later request chooses it for the deck.
- **Status:** confirmed

## Notes

- The owner ruled on 05-11-2026 (UC-010 review, 5A) that decks do not follow a changed design system by themselves.
- The visual style part of legacy FR-106 is dropped (legacy UC-017 review, 05-11-2026): there is no visual style.
