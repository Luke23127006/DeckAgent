id: FR-134
title: "Find an earlier chat by its words"
---

## Requirement

- **Statement:** When the user looks for earlier chats by words, the system shows only the earlier chats whose name or conversation holds those words. When no chat matches, it says so and keeps the words the user gave. Looking for a chat changes no chat.
- **Status:** confirmed
- **Why:** Earlier chats are kept with no time limit [BR-004], so the set grows.
