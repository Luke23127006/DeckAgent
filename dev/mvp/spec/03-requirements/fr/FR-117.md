## Requirement

- **Statement:** The system **offers as available only generation formats** that the **selected model and the current tools, permissions and integrations build now** [BR-011]. It **names each missing tool or permission** and **each material limitation**. It **never changes the selected model**, and **never uses an outside service the user has not set up**, to **make a format available** [NFR-007].
- **Status:** confirmed
