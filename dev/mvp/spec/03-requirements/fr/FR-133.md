## Requirement

- **Statement:** The system lets the user set up, change or remove one outside service of each kind DeckAgent uses [BR-016], with the key of their own account. It checks the key with the service before it saves it, and saves nothing when the service refuses it. It says that requests that use this kind of service send to it.
- **Status:** confirmed
- **Why:** The user chooses and sets up each outside service (DEC-003).
