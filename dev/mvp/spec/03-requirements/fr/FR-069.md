## Requirement

- **Statement:** When the system shows an outline, it shows an overview of the planned slides and the planned content of each planned slide in the language of the deck, and the brief in the language the user writes in. Reading the outline changes no outline, confirms nothing and sends no request. The confirmed outline stays readable and does not change.
- **Status:** confirmed
