---
id: FR-143
title: "Refuse a change of workspace or chat state from a client that is not allowed"
---

## Requirement

- **Statement:** When an **operation that changes the state of a workspace or a chat** comes from a **client that DeckAgent does not allow**, the system **refuses it** and **changes no workspace and no chat**. A **web page outside DeckAgent** is **not an allowed client**.
- **Status:** confirmed
- **Why:** The system runs on the user's computer and **answers local requests**; **without this**, a web page the user opens could **add, rename or remove workspaces and chats**.

## Notes

- The system **does not protect** against **another process that runs with the same operating-system rights** as DeckAgent.
- The system has **no user login**.
- How the system **tells an allowed client from another** is chosen in the implementation plan.
