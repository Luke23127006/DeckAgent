## Requirement

- **Statement:** When the chat has **no selected model that is selectable** [BR-005], the system **does not send the request**, **starts no work** and **keeps the draft**. It **says why**: no provider is set up, no model is added, or the chat has no selected model. It **chooses no model by itself**.
- **Status:** confirmed
