title: "Open an earlier chat"
---

## Requirement

- **Statement:** When the user opens an earlier chat, the system starts no work, sends no request, and changes no chat and no deck. It shows the conversation of that chat in order with the activities of its requests, the deck in its last saved state, and the selected model of that chat; when the chat has no slides yet, it says so. The user is allowed to send a new request in that chat.
- **Status:** confirmed

## Notes

- An outline that waits for confirmation and a first draft that ended early keep the behavior of their own FRs.
- The draft of each chat stays with that chat, whole (FR-038).
