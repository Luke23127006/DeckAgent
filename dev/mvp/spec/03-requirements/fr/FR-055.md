## Requirement

- **Statement:** The system lets the user choose the selected model of a chat among the selectable models of every provider configuration [BR-005], and a reasoning level that the model has. When the system knows no reasoning level of the model, it offers none, and requests run at the default level of the provider. The choice applies from the next request of that chat.
- **Status:** confirmed
