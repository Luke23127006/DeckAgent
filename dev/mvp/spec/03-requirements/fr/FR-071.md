---
id: FR-071
title: "Add a workspace and switch workspaces"
---

## Requirement

- **Statement:** When the user **chooses a readable folder**, the system **sets up a workspace for it**, **names it after the folder** and **makes it the workspace in use**; a folder that is **already the project folder of a workspace** **makes that workspace the workspace in use**, and the system **sets up no second workspace** for it. **Switching to a workspace that is set up** **asks for no folder**, and a **folder that cannot be read** **sets up no workspace**. **Adding or switching** **keeps the current chat and its draft**, **changes no file of the user**, **reads no file of the folder**, **sends nothing to a model** and **stops no request**, and a **new chat joins the workspace in use**.
- **Status:** confirmed

## Notes

- **Renaming a workspace** is **FR-141**. A **folder that had a removed workspace** **sets up a new workspace**; the **chats of the removed one stay ungrouped chats** (FR-073).
- **Starting a new chat** is **FR-053**.
