## Requirement

- **Statement:** The system drafts the outline only from sources the user gave, chose or accepted [BR-013]. When the request has no material and names no source, the system asks which sources to use. It uses only the model's general knowledge after the user confirms it.
- **Status:** confirmed
- **Why:** Teacher feedback of 23-10-2026: with no source given, the user confirms that the deck uses the model's own knowledge.
