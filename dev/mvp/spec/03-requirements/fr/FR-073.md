---
id: FR-073
title: "Remove a workspace"
---

## Requirement

- **Statement:** The system removes a workspace other than the default workspace only after the user confirms, and says before that its project folder and its chats stay. Removing changes no folder and no file of the user, and every chat of the removed workspace joins the default workspace with its conversation, its deck and its selected model [BR-004], and the default workspace becomes the workspace in use when the removed one was. While a request in a chat of the workspace is active, the system removes nothing, says that the request must end first, and stops no request.
- **Status:** confirmed

## Notes

- A chat of a removed workspace has no project folder, as a chat of the default workspace has none, so the agent reaches no folder without an approval (FR-077).
