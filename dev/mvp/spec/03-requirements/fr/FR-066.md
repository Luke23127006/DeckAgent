id: FR-066
title: "Use images on slides"
---

## Requirement

- **Statement:** When a slide needs an image, the system uses an attached image, makes a new image, or uses an image found by public research, as the interview answer or the request asks [NFR-009]. It never changes the selected model to make an image [NFR-007]. It leaves out an image it chose to add and cannot get, and the closing message says so.
- **Status:** confirmed
- **Why:** Teacher feedback of 23-10-2026: slides need images, generated or found on the web.

## Notes

- Images found by public research are allowed.
- The licence and the source of images found by public research are FR-125.
