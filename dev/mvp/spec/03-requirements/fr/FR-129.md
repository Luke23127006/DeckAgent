title: "Offer only sources and images that work now"

## Requirement

- **Statement:** In the interview, the system **suggests public research, new images and images found by public research** **only when an outside service for each one is set up**. When the user **asks for one that is not set up**, the system **says which outside service is missing** and **offers to go on without it**. It **changes no answer of the user by itself**.
- **Status:** confirmed
- **Why:** A **missing service is reported in the interview**, **before the outline is confirmed**; DEC-003 **leaves the setup of each outside service to the user**.
