id: FR-112
title: "Keep built-in design systems as DeckAgent gives them"
---

## Requirement

- **Statement:** The system **never changes or removes a built-in design system**. When the user **asks to change one**, it **changes nothing** and **offers to start a new design system from it**; when the user **asks to remove one**, it **removes nothing** and says that a **built-in design system is never removed**. It **saves no new design system unless the user saves one**.
- **Status:** confirmed
