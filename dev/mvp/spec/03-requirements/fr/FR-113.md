---

## Requirement

- **Statement:** During the interview, the system proposes one available generation format for the deck from the request and the material, and says why [BR-011]. A named available format is proposed as named; with no named format and no special need, the system proposes the default generation format. The user accepts the proposal or chooses another available format, and is allowed to change it until slide generation starts.
- **Status:** confirmed
- **Why:** Teacher feedback of 23-10-2026: the format is chosen up front, because changing it later means building the deck again.

## Notes

- The format is chosen in the interview, before the outline.
