id: FR-018
title: "Stop a request"
---

## Requirement

- **Statement:** The user is allowed to stop an active request. The system then stops the work [NFR-011], shows that it was stopped and not that it failed, and shows each activity still running as stopped. It keeps the request and the finished work and never sends the request again by itself; a later request is new work, not a resumed run.
- **Status:** confirmed
