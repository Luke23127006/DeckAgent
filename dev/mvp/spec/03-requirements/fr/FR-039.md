## Requirement

- **Statement:** The system **shows each saved provider configuration** with its **added models** and **whether it has a saved key**, and **each outside service** the user set up. For a **new provider configuration**, it **offers the built-in providers that no saved provider configuration uses** [BR-005] [BR-008] and a **custom model API**, and says **what the provider needs** [BR-006]. It says that **each request run through a provider configuration goes to its provider**.
- **Status:** confirmed
