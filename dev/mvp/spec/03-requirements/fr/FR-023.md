## Requirement

- **Statement:** **While it builds the slides**, the system **shows the deck canvas** and shows that **work is in progress**. It **shows each slide once it is done** [NFR-009], and **which slides are still to come**. It **does not change which slide the user is looking at**.
- **Status:** confirmed
