## Requirement

- **Statement:** In each chat, the system works on one request at a time and accepts no new request there until the active request ends. A question the system asks ends its request, and the user's reply is a new request. While a request is active, the user is allowed to prepare the next request as the draft, and the material of the active request stays unchanged.
- **Status:** confirmed

## Notes

- Changed vs legacy: the legacy FR kept a request active while it waited for the user's answer (legacy FR-020, dropped). The owner ruled on 04-11-2026 that a reply is a new request.
- A request that waits for the user's approval of a step is not a question: it stays active (owner ruling of 04-11-2026). The approval is FR-076.
