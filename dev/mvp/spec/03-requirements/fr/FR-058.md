title: "Add models to a provider configuration"
---

## Requirement

- **Statement:** The system gets the model catalog of the provider and lets the user add models from it, or give a model ID by hand [BR-005]. It saves only the models the user chose, runs no model to do so, and changes no added model when it gets the catalog. When it does not get the catalog, it says so, and why when it knows, and adding by model ID stays possible.
- **Status:** confirmed
