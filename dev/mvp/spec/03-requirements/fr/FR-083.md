id: FR-083
title: "Choose another project folder for a workspace"
---

## Requirement

- **Statement:** When the user **chooses another folder for a workspace** other than the default workspace, the system **makes it the project folder** of that workspace, **keeps the workspace and its chats**, **reads no file of the folder** because of the choice, and **never changes a project folder by itself**. When the chosen folder is the **project folder of another workspace** or **cannot be read**, the system **changes neither workspace** and says **which workspace uses the folder** or that it **cannot be read**. While a **request in a chat of the workspace is active**, the system **changes no project folder**, says that the **request must end first**, and **stops no request**.
- **Status:** confirmed
