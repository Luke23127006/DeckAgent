---
id: FR-140
title: "Ask which part of the deck a question is about"
---

## Requirement

- **Statement:** When a question does not say which slides or which part of the deck it is about, and the deck and the conversation do not tell, the system changes nothing and asks which part, which ends the request. It offers suggested answers taken from the deck.
- **Status:** confirmed

## Notes

- A question ends the request, and the reply is a new request (FR-014).
