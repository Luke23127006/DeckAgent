## Rule

- **Statement:** The rule sets the design system a deck uses when the user chose none.
- **Status:** confirmed

## Values

### V-1 · Default design system

- **Value:** not set

## Notes

- Proposal: the default is a built-in design system that works in every generation format the system offers.
- The default is a fixed built-in design system; the user does not make another design system the default. The value is chosen in Phase 0 of the MVP, once the built-in design systems are known.
