## Rule

- **Statement:** The rule sets the kinds of outside service the user sets up for DeckAgent. Each kind has at most one set-up service.
- **Status:** confirmed
- **Why:** Public research and web images need a service the user set up (DEC-003).

## Values

### V-1 · Kinds of outside service

- **Value:** Closed list: web search, image service.

## Notes

- Video and audio services, which open-design lists, are not kinds of this rule: no flow uses them.
