---

## Rule

- **Statement:** The rule sets the **theme values every design system has**, and the **kinds of brand file** a design system holds.
- **Status:** confirmed
- **Why:** A design system holds **theme values**, **rules in words**, and the **logo and fonts of the brand**.

## Values

### V-1 · Theme values

- **Value:** not set

### V-2 · Kinds of brand file

- **Value:** **Closed list**: logo, font file.

## Notes

- V-1 is a **closed list of named roles**, such as a main colour, a heading font or a spacing step. It is **set with the first template and theme translator** (DEC-005).
- **Every theme value has a role** of V-1. A **colour or a font the user puts in the theme** of a deck **takes the place of a value with a role**; there is **no theme value without a role**.
