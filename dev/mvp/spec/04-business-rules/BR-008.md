id: BR-008
title: "Provider IDs of provider configurations"
---

## Rule

- **Statement:** The rule sets how many saved provider configurations have the same provider ID, and which provider IDs a custom model API never takes. It sets no total number of provider configurations.
- **Status:** confirmed

## Values

### V-1 · Provider configurations per provider ID

- **Value:** At most one saved provider configuration for each provider ID. A deleted provider configuration does not count.

### V-3 · Provider IDs reserved for built-in providers

- **Value:** Closed list: the provider ID of each built-in provider, also while it has no saved provider configuration.

## Notes

- Value number V-2 is not used.
