id: BR-020
title: "Names refused for a workspace"
---

## Rule

- **Statement:** The **names that the system refuses for a workspace**, compared **after the spaces at both ends are dropped**.
- **Status:** confirmed
- **Why:** A name with **no character** cannot be **told apart in the list**; a **very long name** breaks the list.

## Values

### V-1 · Empty name

- **Value:** a name with **no character** once the spaces at both ends are dropped.

### V-2 · Longest name

- **Value:** **at most 100 characters**, inclusive; a **longer name is refused**. A character is **one Unicode code point** after **NFC normalization**, so "Việt" is **4 characters**.
