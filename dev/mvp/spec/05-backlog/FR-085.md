## What it is

An export of a deck, a conversation or a session archive writes its file only to a
destination the user chooses for that export. A file of the same name there is never
replaced: the system says that the name is taken. With no destination chosen, the system
writes no file and changes no deck and no chat. A failed write gives no finished file and
says why when the reason is known.
