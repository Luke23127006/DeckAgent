## What it is

The user has a deck source that DeckAgent exported, and wants to change it again in
DeckAgent as the same deck, instead of using it as material for a new deck.

## Belongs to

None.

## Why parked

In the spec, an exported source archive attached to a request is material like any
attachment, and nothing is imported as a deck to change (legacy FR-123 dropped).

## Reconsider when

UC-004 (export the deck to a file) or UC-016 (export a session for reading or handover) is promoted from the backlog.

## Source

- PO ruling in the UC-012 review, 05-11-2026.
- `docs/spec/04-requirements/fr/FR-123.md` (at commit `71ff143`): the opposite
  rule, an archive is material only.

## Decided

PO, 05-11-2026. Given an ID and moved to the backlog on 05-11-2026.
