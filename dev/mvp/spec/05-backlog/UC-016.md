## What it is

The user wants a record of the work in a chat outside DeckAgent: to read the conversation
and its results elsewhere, or to hand the session over with its records and attachments.
The record holds no credential that DeckAgent keeps, and the chat does not change.

Requirement only this use case would cite:

- FR-080, export the session of a chat: a conversation file to read, or a session archive
  for review or handover that says what it holds before it is written. It holds the
  conversation, the records of the requests, the outline, the deck state and the
  attachments of the session; no other file of the user, no copy of the project folder
  and no key, token or other credential [NFR-006]. A chat with no sent request has nothing
  to export. The product imports no archive.
- The destination the user chooses is FR-085, shared with UC-004.

Flows to cover: no sent request; export fails; the file name is taken; no destination
chosen.

## Belongs to

None.

## Why parked

Export is not in the MVP.

Not set by the PO.
