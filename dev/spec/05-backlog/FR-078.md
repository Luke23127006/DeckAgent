## What it is

The user sees how much of the context of the selected model the conversation and the
draft of a chat use. The system says whether each number is an estimate of DeckAgent or
one the provider reported, and invents no number it cannot compute. Seeing the usage
changes no conversation, draft or attachment.

## Belongs to

No target block yet. Legacy UC-015 (see the context of a chat and compact it), now
retired, cited it. Promoted, it would join UC-003 (send a request and wait for its work).

## Why parked

The system summarizes the conversation by itself when it outgrows the context (FR-079),
so the user needs no number to decide when to compact. The OpenCode docs show no context
usage to read from.

## Reconsider when

Runtime research shows that OpenCode reports context usage per session, or users ask to
see how full a chat is.

## Findings

- The legacy FR also suggested compacting at a warning threshold (legacy BR-010, at least
  85% of the context window). BR-010 is dropped: with no compact command there is
  nothing to suggest. A promoted FR-078 shows usage only.
- Legacy open question kept: does each provider report a context usage per model, and
  which numbers are exact?
