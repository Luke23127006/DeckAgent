## What it is

After the user confirms, the added models of a provider configuration of a built-in
provider become exactly its default models, and each other added model is removed. A
chat whose selected model was removed then has no selected model.

## Belongs to

UC-005 (set up the services DeckAgent uses with my own keys).

## Why parked

The target has no default models of a provider (BR-005 V-5 retired). The user adds models
from the model catalog.

## Reconsider when

The runtime research finds that OpenCode gives no model catalog.
