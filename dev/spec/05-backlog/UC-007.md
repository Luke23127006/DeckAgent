## What it is

The user sees a small thing to fix in a deck the system made, such as a wrong word or a
slide in the wrong place. Fixing it by hand is quicker than describing it in a request.
The user wants only that change, without waiting for the model or risking other slides.

Legacy flows: add, delete, duplicate or move a slide; undo the last change by hand; a
part that is not changed by hand; cancel the change. The legacy file cites no FR; every
response was `FR-?`.

## Belongs to

None.

## Why parked

The PO does not build changes by hand now, and keeps them for later instead of dropping
them. What each generation format supports for changes by hand is not decided.

## Reconsider when

Not set by the PO.

## Findings

- PO ruling of 05-11-2026: each generation format states what it supports. Changes by
  hand come first for the formats that look most feasible (agent estimate, not checked:
  HTML with Reveal.js, and Markdown with Marp or Slidev); PPTX, LaTeX, Google Slides,
  design tools and vector formats wait. The level of support per format is not decided.
  The plan was to record this as DEC-008 in this review.
- Conflict: editing the Markdown file in VS Code needs the file outside DeckAgent, but
  [DEC-006](../../decisions/DEC-006-where-chat-work-is-kept.md) ruling A keeps the deck
  source in DeckAgent's own data. Option B or C fits the teacher. The question for the TA:
  is it the file DeckAgent uses, with changes coming back, or an exported copy?
- [DEC-005](../../decisions/DEC-005-model-writes-source-within-template.md) leaves open
  whether the check of each write (FR-092) also applies to a change by hand, and whether
  the user edits the theme by hand. By
  [DEC-007](../../decisions/DEC-007-how-a-design-system-bounds-the-deck.md), a colour or
  font the user chose is never a fault of the check.
- Undo of a change by hand and going back to an earlier state (UC-008 in the backlog) are
  settled together; read that item first.
- The deck source is the working files of the deck: the system and the user change the
  same files.

## Decided

PO, 05-11-2026, in the check of legacy UC-008: export and changes by hand go to the
backlog.
