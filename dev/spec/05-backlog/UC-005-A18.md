## What it is

Instead of giving a key, the user chooses a coding-agent program already on their
computer, signed in with that program's own login. DeckAgent runs the model of a chat
through that program.

## Belongs to

UC-005 (set up the services DeckAgent uses with my own keys), at the step where the user
chooses a provider.

## Why parked

The target sets up a provider with a key the user enters only (owner ruling A in the
UC-005 review).

## Reconsider when

The runtime research of the first build that touches models has said how OpenCode runs
models and keeps keys.
