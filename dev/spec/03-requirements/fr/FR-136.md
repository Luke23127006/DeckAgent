## Requirement

- **Statement:** When a request asks named slides not to follow a rule in words of the design system of the deck, such as leaving the logo off them, the system follows the request on those slides only and asks for no approval. The closing message names each rule that those slides do not follow. The design system and the theme of the deck stay as they were.
- **Status:** confirmed
- **Why:** Owner ruling of 05-11-2026 (legacy UC-017 review, 5A): the choice of the user wins, as for a colour or a font in DEC-007.

## Notes

- Replaces legacy FR-105 (resolve design rule conflicts and exceptions). With no visual style, no second set of rules conflicts with the design system, and a design system has no Required or Preferred Rules (legacy FR-104 dropped).
