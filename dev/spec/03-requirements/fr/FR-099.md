id: FR-099
title: "Take design rules from brand files"
updated: 05-11-2026
---

## Requirement

- **Statement:** When the user gives brand files, such as a brand guide, a presentation, a logo, a font file or a design system package of another product, the system takes the theme values, the rules in words and the brand files it finds in them [BR-017]. It names the file each one came from, and each file or part it cannot use, with the reason. It never says that it found every rule in the files.
- **Status:** confirmed

## Notes

- The owner ruled on 05-11-2026 (UC-010 review, 7A) that a design system package of another product, such as open-design, is a brand file like any other, with no import flow of its own.
- Owner ruling of 05-11-2026 (legacy UC-017 review, 2A): a reference presentation is a brand file; the reference part of legacy FR-103 is merged here. The design system takes no content of it.
