## Requirement

- **Statement:** The user is allowed to choose a built-in or a saved design system for a deck, and a deck uses one. The slides use its theme, the choice changes no rule of the design system, and when the user chooses none, the slides use the default design system [BR-003]. Choosing another design system for a deck with slides changes the theme of the whole deck, keeps the content, the design changes of each slide and each colour or font the user chose for a part of a slide, puts the theme values of the new design system in place of those the user had put in the theme and names each one replaced, and checks each slide again.
- **Status:** confirmed

## Notes

- The PO ruled on 04-11-2026 (UC-002 review, DEC-005) that a deck uses one design system and that a change of design system keeps the design changes made by earlier requests.
- A colour or a font the user chose for a part of a slide is kept on a change of design system (owner ruling of 05-11-2026, [DEC-007](../../../decisions/DEC-007-how-a-design-system-bounds-the-deck.md)).
- A colour or a font the user put in the theme of the deck in place of a theme value is not kept: choosing another design system asks for its look, and keeping the user's values would mix two looks. The system names each one it replaces, so the user is able to ask for it again (owner ruling 8A of 05-11-2026, legacy UC-017 review).
