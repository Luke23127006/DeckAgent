## Requirement

- **Statement:** The user is allowed to choose a built-in or a saved design system for a deck, and a deck uses one. The slides use its theme, the choice changes no rule of the design system, and when the user chooses none, the slides use the default design system [BR-003]. Choosing another design system for a deck with slides changes the theme of the whole deck, keeps the content and the design changes of each slide, and checks each slide again.
- **Status:** confirmed

## Notes

- The PO ruled on 04-11-2026 (UC-002 review, DEC-005) that a deck uses one design system and that a change of design system keeps the design changes made by earlier requests.
