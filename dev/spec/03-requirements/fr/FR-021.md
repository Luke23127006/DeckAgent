## Requirement

- **Statement:** Before the first outline, the system asks about each interview topic that the request and the material do not answer [BR-013]. It offers suggested answers, accepts the user's own answer or a skip, and lets the user add other requirements in their own words. For a skipped question it uses an assumption, except for the topic: while the topic stays unknown, the system drafts no outline and asks for the topic again.
- **Status:** confirmed
- **Why:** Teacher feedback of 23-10-2026: an interview with suggested answers comes before the outline.

## Notes

- Rewritten from legacy FR-021 ("Ask before drafting the first outline"), which asked only when the topic was unknown or an open point changed the outline a lot. The owner ruled on 04-11-2026 for a fixed list of topics that skips what the request already answers.
