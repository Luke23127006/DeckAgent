## Requirement

- **Statement:** Before the first outline, the system asks in one interview message about each interview topic that the request and the material do not answer [BR-013], in the language the user writes in. It offers suggested answers, accepts the user's own answer or a skip for each question, lets the user skip all remaining questions at once, and lets the user add other requirements in their own words. For a skipped question it uses an assumption, except for the topic: while the topic stays unknown, the system drafts no outline and asks for the topic again.
- **Status:** confirmed
- **Why:** Teacher feedback of 23-10-2026: an interview with suggested answers comes before the outline.

## Notes

- Rewritten from legacy FR-021 ("Ask before drafting the first outline"), which asked only when the topic was unknown or an open point changed the outline a lot. The owner ruled on 04-11-2026 for a fixed list of topics that skips what the request already answers.
- The owner ruled on 04-11-2026 that the interview is one message, not one question at a time, so that up to nine topics do not take nine rounds; the brief shown with the outline lets the user check every assumption.
