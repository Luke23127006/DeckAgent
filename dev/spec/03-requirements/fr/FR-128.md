## Requirement

- **Statement:** When a message asks a question and asks for no change, the system answers it and changes no outline, brief or slide. The current outline stays the current outline.
- **Status:** confirmed
- **Why:** The PO ruled on 04-11-2026 that a question about an unconfirmed outline is answered, not taken as a revision.
