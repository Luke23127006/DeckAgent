title: "Save a design system made from another one"
updated: 05-11-2026
---

## Requirement

- **Statement:** The system starts a new design system from an existing design system the user chooses, or from the default design system when the user chose none [BR-003], and keeps each theme value the user does not change [BR-017]. On save, it adds a new custom design system under a name no other design system has, or keeps the name of the custom design system the user changed. Saving changes no deck and no other design system.
- **Status:** confirmed

## Notes

- The owner ruled on 05-11-2026 (UC-010 review, 3A) that a design system always starts from an existing one, so every design system has every theme value.
