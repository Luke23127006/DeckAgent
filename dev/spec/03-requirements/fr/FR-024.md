## Requirement

- **Statement:** When the first draft is done, the system shows a closing message. The message tells what each slide holds, which assumptions were used, which text is placeholder and which content did not come from the user's material [BR-?: disclosure of content not from the user's material]. It never says that the system checked a figure or a claim that it did not check.
- **Status:** confirmed
