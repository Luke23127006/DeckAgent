## Requirement

- **Statement:** When the user asks for earlier work, the system shows the earlier chats the user is allowed to open [BR-004], including chats from before DeckAgent last started. It names each chat from its content, and says when the chat last changed and whether it has slides. With no earlier chat it says so, and the current chat and its draft stay as they were.
- **Status:** confirmed

## Notes

- Which earlier chats belong to the workspace in use, and the chats of a removed workspace, are reviewed with legacy UC-013.
