## Requirement

- **Statement:** A follow-up request uses the sources of the brief and the material given earlier in the chat. It uses another source, such as public research, only when the request names it. When the change needs content of a kind that needs a source [BR-015] and no source gives it, the system writes a placeholder on the slide instead of inventing it.
- **Status:** confirmed
- **Why:** The PO ruled on 04-11-2026 that a follow-up request keeps the source choice of the first draft (FR-124), so that a new slide cannot bring in made-up figures.
