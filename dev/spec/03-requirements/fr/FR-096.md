## Requirement

- **Statement:** Before a design system is saved, the system shows each theme value, each rule in words and each brand file of the proposed design system [BR-017], with a sample slide made with it. It names each rule it cannot use, with the reason, and each two rules that do not agree, with where each came from, and it chooses neither of two rules that do not agree. Showing a proposed design system changes no deck.
- **Status:** confirmed

## Notes

- Rewritten from legacy "Review and validate design system rules". The owner ruled on 05-11-2026 (UC-010 review, 1A) that a design system holds theme values and rules in words, with no Required or Preferred Rules: code checks the theme values (FR-092), and the rules in words are judged.
- Legacy "what a design system needs at least" is dropped: a new design system starts from a complete one (FR-097).
- Legacy FR-100 (create and preview a custom visual style) is merged here on 05-11-2026 (legacy UC-017 review): rules of density, headings, hierarchy, charts and images are rules in words of a design system.
