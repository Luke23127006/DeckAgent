## Requirement

- **Statement:** The system sends a request only when it has request text, at least one ready attachment, or both, and no attachment is being prepared or rejected. It does not send request text longer than the maximum request length [BR-002]; it says that the text is too long and keeps the draft. An empty request gets no error message.
- **Status:** confirmed
