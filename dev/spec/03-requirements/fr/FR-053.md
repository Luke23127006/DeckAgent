## Requirement

- **Statement:** Starting a new chat keeps every other chat, its deck and its draft as they were, and stops no request. The new chat becomes the current chat in the workspace in use, with no conversation, no deck and an empty draft, and takes nothing from another chat. It gets the selected model and the reasoning level of the most recent choice of a model in any chat when that model is still selectable [BR-005], and otherwise no selected model.
- **Status:** confirmed
- **Why:** Owner ruling of 05-11-2026 (review of legacy UC-012, 2A): carry on with the model the user chose last, with one simple rule.

## Notes

- Changed vs legacy: legacy walked back through earlier choices until it found a selectable model; that chain is dropped. Legacy removed the unsent attachments of the chat the user left; the draft of each chat is now kept whole (FR-038). A model removed and added again counts when it is selectable. Legacy gave each chat its own permission; the reach of the agent is now fixed for every chat (FR-077).
- A chat holds at most one deck (glossary), so another deck starts in a new chat (owner ruling 3A of 05-11-2026).
