## Requirement

- **Statement:** The system offers to confirm a current outline that is not empty. A clear confirmation confirms only the current outline and the brief shown with it, and starts slide generation; a message that also asks for a change is never taken as a confirmation. For an empty outline, the system confirms nothing and suggests asking for a revision instead.
- **Status:** confirmed

## Notes

- Legacy FR-006 (refuse to confirm an empty current outline) is merged here.
- The confirmation of the generation format moved into the interview (FR-113), so the outline is the only confirmation before slide generation.
