## Requirement

- **Statement:** The system uses no image found by public research whose licence is known and not accepted [BR-014]. It marks an image whose licence is unknown. The closing message names the source of each image found by public research.
- **Status:** confirmed

## Notes

- Split from FR-066 on 04-11-2026, so that the licence check is separate from the choice of image.
