## Requirement

- **Statement:** After the user confirms the outline, the system builds the slides from the confirmed outline, in the generation format of the deck. Each planned slide gives one slide, in the order of the outline, keeping the meaning of its planned content. The slides are built from the template of the generation format and use the theme of the chosen design system, or of the default design system when the user chose none [BR-003].
- **Status:** confirmed
