## Requirement

- **Statement:** After the user confirms the outline, the system builds the slides from the confirmed outline, in the generation format of the deck. Each planned slide gives one slide, in the order of the outline, keeping the meaning of its planned content. Each slide uses a layout of the template of the generation format that fits its planned content, or a new layout when none fits, and the slides use the theme of the chosen design system, or of the default design system when the user chose none [BR-003].
- **Status:** confirmed

## Notes

- Layouts that fit and a new layout when none fits: owner ruling 1B of 05-11-2026, [DEC-007](../../../decisions/DEC-007-how-a-design-system-bounds-the-deck.md). Each layout states the kinds of content it serves and how much it holds.
