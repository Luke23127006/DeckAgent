## Requirement

- **Statement:** The system does not finish a slide it builds or changes while the slide has known missing required content, wrong facts, unreadable content [NFR-009], or a colour or a font that is not from the theme of the deck. It corrects the fault within the active request. When it cannot correct the fault, it ends the request unfinished.
- **Status:** confirmed

## Notes

- The check of colours and fonts against the theme was added on 04-11-2026 by DEC-005 (setting C1: the model corrects its own fault; code fixes nothing by itself).
