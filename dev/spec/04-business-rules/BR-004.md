## Rule

- **Statement:** The rule sets which chats the system keeps as earlier work that the user is allowed to open, and how long it keeps them.
- **Status:** confirmed

## Values

### V-1 · Which chats are kept

- **Value:** Every chat in which the user sent at least one request. A chat with no sent request is not required to appear.

### V-2 · How long chats are kept

- **Value:** No time limit. The system deletes no chat, conversation or deck because of its age.

## Notes

- V-3 (chats of a removed workspace) is not migrated; it is reviewed with legacy UC-013 and keeps its ID.
- No time limit is no promise against a loss DeckAgent does not cause, such as a file the user removes or a lost disk.
