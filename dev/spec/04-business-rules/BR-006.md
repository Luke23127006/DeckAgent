## Rule

- **Statement:** The rule sets what the user gives for a provider configuration before its models run, for each built-in provider and for a custom model API, and which settings of a saved provider configuration the user changes.
- **Status:** confirmed

## Values

### V-1 · What each built-in provider needs

- **Value:** not set
- **Why:** Besides a key, what each built-in provider needs, and whether its base URL changes, waits for checks with that provider.

### V-2 · What a custom model API needs

- **Value:** Open list: a provider ID, a base URL, an API protocol, and a key only when the model service needs one.

### V-3 · Settings the user changes after saving

- **Value:** Open list: the key, the base URL of a custom model API, and the base URL of a built-in provider only where V-1 allows it. Never the provider ID.
