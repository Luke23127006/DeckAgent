## Rule

- **Statement:** The rule sets the built-in templates of each available generation format, and the template a deck uses when the user chose none.
- **Status:** confirmed
- **Why:** Owner ruling of 05-11-2026 (legacy UC-017 review, 3B): several prebuilt templates give decks more looks without moving the choice of layouts to the model.

## Values

### V-1 · Built-in templates of each generation format

- **Value:** not set

### V-2 · Default template of each generation format

- **Value:** not set

## Notes

- Every template is built in; there is no template the user saves. A version spec is allowed to narrow V-1 to one template per generation format.
