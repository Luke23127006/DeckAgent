## Rule

- **Statement:** The rule sets the output kinds the user can choose when exporting a deck: the file kind of a source export and the formats of a static export.
- **Updated at:** 28-10-2026

## Values

### V-1 · Source export output kind

- **Value:** ZIP.

### V-2 · Static export formats

- **Value:** Closed list: PDF, PNG and JPEG.

## Notes

- No SVG export, no editable or fixed category and no automatic conversion of the source to another generation format belong to this rule.
- How each output kind packages the slides is behavior. It is not part of this rule.
