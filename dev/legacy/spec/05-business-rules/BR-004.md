id: BR-004
title: "Chats kept as earlier work"
---

## Rule

- **Statement:** The rule sets which chats the system keeps as earlier work that the user can open. It also sets how long it keeps them, and which chats stay reachable when a workspace is removed.
- **Updated at:** 26-10-2026

## Values

### V-1 · Which chats are kept

- **Value:** Every chat in which the user sent at least one request. A chat with no sent request is not required to appear.

### V-2 · How long chats are kept

- **Value:** No time limit. The system deletes no chat, conversation or deck because of its age.

### V-3 · Chats of a removed workspace

- **Value:** Every chat of a workspace stays reachable after that workspace is removed. Removing a workspace changes no folder, no file of the user, no chat, no conversation and no deck on the computer, and the work DeckAgent saved for those chats stays as it was. Those chats are found among the ungrouped chats and belong to no workspace.

## Notes

- No time limit is not a promise against loss that DeckAgent does not cause. Examples are files the user removes on purpose and a lost disk. A project folder that is missing, moved, replaced or gone takes away the files of the user, not the chats saved for its workspace (FR-074).
- This rule adds no way to delete a chat or a deck.
- V-3 says that the chats of a removed workspace are found among the ungrouped chats. It sets no other place for them and no other way to reach them.
