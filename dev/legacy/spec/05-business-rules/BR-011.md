## Rule

- **Statement:** The rule sets the categories of generation format that the ideal product covers, and the generation format the system proposes when nothing asks for another one.
- **Updated at:** 28-10-2026

## Values

### V-1 · Generation format categories

- **Value:** Closed list of seven categories:
  - Web-based. Examples: HTML, Reveal.js.
  - Markdown-based. Examples: Marp, Slidev, Quarto.
  - PowerPoint-native. Example: PPTX.
  - Google Slides-native. Example: Google Slides.
  - LaTeX-based. Example: Beamer.
  - Vector / Scene-based. Example: an SVG or Excalidraw-compatible scene.
  - Design-tool-native. Examples: Figma Slides, Penpot.

### V-2 · Default generation format

- **Value:** HTML.

## Notes

- A category is not a generation format the user can choose. The examples show what each category means. They are not a list of formats the system can build.
- This rule sets no closed list of available generation formats. What the system can build changes with its tools, permissions and integrations. Availability is decided in each context, not here.
- A native category means that the result can be changed in the named tool. A PPTX made of one picture per slide is not PowerPoint-native.
- This rule defines values only. How the system proposes, shows and confirms a generation format is behavior, and it is not part of this rule.
