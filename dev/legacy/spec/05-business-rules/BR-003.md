## Rule

- **Statement:** The rule sets the default design system: the design system that a deck uses when the user chose none.
- **Updated at:** 26-10-2026

## Values

### V-1 · Default design system

- **Value:** not set
- **Why:** No decision has selected the default design system, so its colours, fonts and other design rules are still open. A deck uses it when the user chose no design system.
