id: NFR-014
title: "Build from source and run on Windows"
---

## Requirement

- **Quality attribute:** portability
- **Statement:** A user can get the source code of DeckAgent, build it and run it on their own Windows computer. This needs no service run by the DeckAgent team.
- **Updated at:** 25-10-2026

## Verification

### M-1 · Build and start from source on Windows

- **Conditions:** A clean Windows computer. The report names its Windows version, its hardware and its browser. It holds only the tools that the published build steps name. The network reaches public package sources. Boundary: product-controlled. Provider-dependent conditions: none.
- **Measure:** Whether a person who follows the published steps can build DeckAgent, start it and open its Local Web interface. Whether any step needs a service run by the DeckAgent team.
- **Method:** Follow the published steps on each check computer. Record each step that fails or needs help beyond the steps.
- **Target:** DeckAgent builds, starts and opens. No step needs a service run by the DeckAgent team.
- **Met when:** Every check computer meets the target.

### M-2 · Selected flows on Windows

- **Conditions:** The check computers of M-1. The acceptance checks of the selected flows. Boundary: product-controlled. Provider-dependent conditions: none change the result. A model service returns fixed content.
- **Measure:** Whether each acceptance check passes on each check computer.
- **Method:** Run the acceptance checks on each check computer. Record each check that fails there and passes elsewhere.
- **Target:** Every acceptance check passes.
- **Met when:** Every check computer meets the target.
- **Why:** A build that starts is not enough when a flow fails on Windows. Windows is the platform on which DeckAgent is checked. Trade-off: the checks run on Windows as well as on the computers of the team.

## Notes

- This requirement applies to the whole product.
- Windows comes first. The requirement promises nothing for every Windows version, device or hardware. It promises nothing for another platform.
- Public package sources are not services run by the DeckAgent team.
