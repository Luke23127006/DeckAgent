---
id: FR-102
title: "Remove a custom visual style"
---

## Requirement

- **Statement:** The system removes a custom visual style when the user asks. The visual style is no longer offered for later decks. Removing it changes no design system, no other visual style and no existing deck.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · A custom visual style is removed

- **Given:** "Report" and "Notes" are saved as custom visual styles. A deck of five slides was built with "Report".
- **When:** The user removes "Report".
- **Then:**
  - "Report" is no longer among the visual styles the user can choose.
  - Every slide of the deck is as it was.
  - "Notes" holds the same rules as before.
- **Check:** deterministic

### AC-2 · The deck stays editable

- **Given:** The state of AC-1.
- **When:** The user asks to change the heading of slide 3.
- **Then:**
  - The system changes slide 3.
  - The deck still holds five slides.
  - Slides 1, 2, 4 and 5 are as they were.
- **Check:** deterministic

### AC-3 · No design system changes

- **Given:** The design system "Acme" is saved. The custom visual style "Report" is saved.
- **When:** The user removes "Report".
- **Then:**
  - "Acme" holds the same rules as before.
  - "Acme" remains among the design systems the user can choose.
- **Check:** deterministic
