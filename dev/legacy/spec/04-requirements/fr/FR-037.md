---
id: FR-037
title: "Keep a disputed point open in the outline"
---

## Requirement

- **Statement:** When material disagrees on a point the outline needs, the system does not decide which part is correct. When the disagreement would materially change the planned content, it asks the user before drafting the outline. The user can select a source or leave the point unresolved. When an outline proceeds with the point unresolved, the outline marks it as open. The user can confirm that outline with the point still open. A slide then shows the point as unresolved and presents no disputed figure as settled.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · No part is called correct

- **Given:** A chat with no deck. The request is "a talk on our survey, from this report". The text of the report says that satisfaction rose by 12%. The results table of the report says 15%.
- **When:** The system shows the outline proposal.
- **Then:**
  - Neither the proposal nor its message says that 12% or 15% is the correct figure.
- **Check:** judged

### AC-2 · Disputed point is marked as open

- **Given:** The state of AC-1.
- **When:** The user reads the outline proposal.
- **Then:**
  - The planned slide that uses the rise in satisfaction marks that point as open.
  - The user can tell that the figure is for the user to decide.
- **Check:** judged

### AC-3 · The user's decision settles the point

- **Given:** The state of AC-1. The outline is not confirmed.
- **When:** The user sends "use 15%, from the results table".
- **Then:**
  - The new outline proposal uses 15% for the rise in satisfaction.
  - It no longer marks that point as open.
- **Check:** judged

### AC-4 · An open point stays unresolved on the slide

- **Given:** The state of AC-2. The user confirms the outline without settling the rise in satisfaction.
- **When:** The system has built the slide that uses the rise in satisfaction.
- **Then:**
  - The slide shows that the rise in satisfaction is still unresolved.
  - The slide does not give 12% or 15% as the settled figure.
  - The slide gives no other figure for the rise.
- **Check:** judged

### AC-5 · Important conflict is clarified before the outline

- **Given:** A request asks for a deck whose main claim depends on survey satisfaction. The summary says the rise is 12%, and the results table says 15%. The request does not choose between them.
- **When:** The system prepares the first outline.
- **Then:**
  - The system asks the user to choose the source, leave the point unresolved, or change the planned claim.
  - It gives no settled figure before the user answers.
  - No outline is shown while the answer needed for the central claim is still missing.
- **Check:** judged

### AC-6 · User leaves the disagreement unresolved

- **Given:** The state after AC-5. The user chooses to leave the survey rise unresolved.
- **When:** The system shows the outline.
- **Then:**
  - The outline marks the survey rise as unresolved.
  - The outline presents neither 12% nor 15% as the settled figure.
  - The user can still confirm the outline.
- **Check:** judged

## Notes

- Telling the user which parts disagree, and where each one is, is covered by FR-011.
- The revision in AC-3 follows FR-005.
- AC-4 asks for no exact wording. A later request can settle the point. FR-027 covers that change.
