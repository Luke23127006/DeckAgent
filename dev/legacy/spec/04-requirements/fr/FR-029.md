---
id: FR-029
title: "Report the change made to the deck"
---

## Requirement

- **Statement:** While it changes the deck, the system says in the conversation which slides it is changing. When the work is done, the deck canvas shows the changed slides [NFR-009]. A closing message names each slide changed or added and says what changed in it. It also says that no slide outside the scope changed. It also names any significant limitation of the changed slides that the system knows and has not corrected.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · Slides being changed are named

- **Given:** A deck of five slides. The user sent "make slides 2 and 4 shorter".
- **When:** The system works on the request.
- **Then:**
  - The conversation says that the system is changing slides 2 and 4.
  - The conversation names no other slide as being changed.
- **Check:** judged

### AC-2 · Changed slides are shown

- **Given:** The state of AC-1.
- **When:** The system has finished the request.
- **Then:**
  - The deck canvas shows slides 2 and 4 with their change.
- **Check:** deterministic

### AC-3 · Closing message names the changed slides

- **Given:** The state of AC-2.
- **When:** The user reads the closing message.
- **Then:**
  - The message names slides 2 and 4 as changed.
  - The message names no other slide as changed.
- **Check:** deterministic

### AC-4 · Closing message says what changed

- **Given:** The state of AC-2.
- **When:** The user reads the closing message.
- **Then:**
  - For slides 2 and 4, the message says what changed in each.
- **Check:** judged

### AC-5 · Added slide is named

- **Given:** A deck of five slides. The user sent "add a slide on costs after slide 2". The system has finished the request.
- **When:** The user reads the closing message.
- **Then:**
  - The message names the slide on costs as added.
- **Check:** judged

### AC-6 · Message says nothing else changed

- **Given:** The state of AC-2.
- **When:** The user reads the closing message.
- **Then:**
  - The message says that the system changed no slide outside the scope of the request.
- **Check:** judged

### AC-7 · Known significant limitation of a changed slide is disclosed

- **Given:** A user asks to reorganize slide 3 of a deck. The system finishes the change. Slide 3 keeps its facts and remains readable. The system knows that its main comparison is still hard to follow, but the claim is not misleading.
- **When:** The user reads the closing message.
- **Then:**
  - The message names the remaining limitation of slide 3.
  - The message still says what changed in slide 3.
  - The message does not say that the request failed solely because of this limitation.
- **Check:** judged

## Notes

- The closing message is no proof of preservation. FR-027 checks it by comparing the deck before and after the request.
- AC-3 is checked by comparing the slides the message names with the slides that changed.
