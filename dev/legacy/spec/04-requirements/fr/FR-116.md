---
id: FR-116
title: "Keep the generation format locked for one deck"
---

## Requirement

- **Statement:** The generation format of a deck is locked when slide generation starts, also when no slide is finished yet. It stays the same after a stop or a failure, after follow-up requests and edits, after export and after the chat is opened again. The system refuses a request to change the generation format of an existing deck. It converts nothing by itself. The user can see which generation format the deck uses.
- **Updated at:** 28-10-2026

## Acceptance conditions

### AC-1 · Locked at the start of slide generation

- **Given:** The user confirmed an outline and then Marp as the generation format.
- **When:** Slide generation starts.
- **Then:**
  - The generation format of the deck is Marp.
  - The conversation shows that the deck uses Marp.
- **Check:** deterministic

### AC-2 · Locked after a failure with no finished slide

- **Given:** Slide generation started in Marp. The model provider failed before any slide was finished.
- **When:** The user asks "make it in HTML instead".
- **Then:**
  - The generation format of the deck stays Marp.
  - The system says that the format of this deck is locked.
  - The confirmed outline and the conversation are the same as before.
- **Check:** deterministic

### AC-3 · Request to change the format of a finished deck

- **Given:** A deck of six finished slides in HTML.
- **When:** The user asks to change the deck to PPTX.
- **Then:**
  - The deck keeps six slides, and each slide is the same as before.
  - The generation format stays HTML.
  - No second deck appears in the chat.
  - The system says that the user can export the source and ask for a new deck in a new chat.
- **Check:** deterministic

### AC-4 · Format survives follow-up work and reopening

- **Given:** A deck of four slides in Slidev.
- **When:** The user sends a follow-up change, exports the deck, and then opens the chat again.
- **Then:**
  - After each action, the generation format of the deck is Slidev.
- **Check:** deterministic

## Notes

- Before slide generation starts, the user can still change the selected generation format. FR-114 and FR-115 cover that choice.
