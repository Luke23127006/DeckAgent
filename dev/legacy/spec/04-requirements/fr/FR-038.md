---
id: FR-038
title: "Keep the chat while a place for setup or tools is open"
---

## Requirement

- **Statement:** The user can open a place of the chat from the conversation: the skills dashboard, the model setup, the permission of the chat, the context usage or the export of the chat. Opening any of them adds nothing to the request text and sends nothing. When the user goes back to the chat, the conversation, the request text and the attachments are as they were. This holds whether or not the user saved in the place they opened.

## Acceptance conditions

### AC-1 · Opening the model setup changes nothing in the chat

- **Given:** No provider configuration is saved. A chat with no active request. The request area holds the request text "a talk on our pilot results" and the attachment "notes.docx".
- **When:** The user opens the model setup.
- **Then:**
  - The system opens the model setup.
  - The request text is still "a talk on our pilot results". Nothing was added to it.
  - "notes.docx" is still in the request area, unchanged.
  - The conversation shows no new message.
  - No request starts.
- **Check:** deterministic

### AC-2 · Back to the chat after saving

- **Given:** The state after AC-1.
- **When:** The user saves a complete provider configuration and goes back to the chat.
- **Then:**
  - The conversation is the same as before the setup was opened.
  - The request area holds the same request text and "notes.docx", unchanged.
- **Check:** deterministic

### AC-3 · Back to the chat without saving

- **Given:** The state after AC-1.
- **When:** The user leaves the model setup without saving and goes back to the chat.
- **Then:**
  - The conversation is the same as before the setup was opened.
  - The request area holds the same request text and "notes.docx", unchanged.
- **Check:** deterministic

### AC-4 · The same for the other places of the chat

- **Given:** The state after AC-1.
- **When:** In separate runs, the user opens the skills dashboard, the permission of the chat, the context usage of the chat and the export of the chat, and in each run goes back to the chat.
- **Then:**
  - In each run, the conversation is the same as before the place was opened.
  - The request text and "notes.docx" are unchanged, and no request starts.
  - Nothing was added to the request text.
- **Check:** deterministic

## Notes

- What each place holds is behavior of its own use case: the skills dashboard is not written yet, the model setup is UC-005, the permission is UC-014, the context usage and compact are UC-015, and the export is UC-016.
- What the model setup itself keeps after saving or leaving is covered by FR-041 and FR-044. Which model a later request uses is covered by FR-042 and FR-056.
