---
id: FR-099
title: "Extract design system rules from brand materials"
---

## Requirement

- **Statement:** When the user gives a brand guide or brand files, the system takes the brand identity rules it can find. It names the file each rule came from and the material it cannot use. It does not claim to find every rule in the files.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · Rules are taken from the files

- **Given:** The user gives a brand guide that gives a main brand colour, a heading font and a logo.
- **When:** The system has read the brand guide.
- **Then:**
  - The proposed design system holds each of the three rules.
  - Each rule names the brand guide as its source.
  - A representative slide shows the three rules.
- **Check:** judged

### AC-2 · Unusable material is named

- **Given:** The user gives a logo file whose format the system cannot read.
- **When:** The system has read the files.
- **Then:**
  - The system names that file and says why it cannot use it.
  - The proposed design system holds no logo rule taken from that file.
  - The system does not say that it found every rule in the files.
- **Check:** judged

### AC-3 · Each rule names its source

- **Given:** The user gives two files. One gives the brand colours. The other gives the heading and body fonts.
- **When:** The system has read both files.
- **Then:**
  - Each colour rule names the first file.
  - Each font rule names the second file.
- **Check:** deterministic
