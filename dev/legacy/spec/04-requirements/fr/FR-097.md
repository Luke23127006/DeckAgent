---
id: FR-097
title: "Save and revise a design system"
---

## Requirement

- **Statement:** The system saves a custom design system that the user finishes, and adds it to the design systems the user can choose. The user can start one from brand attributes and rules they give, or from a saved design system, including a built-in one. The system can change a saved custom design system and keep its name. Saving or changing a custom design system changes no deck, no visual style and no other design system. A built-in design system keeps its original definition [FR-112].
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · A new custom design system is saved

- **Given:** The user reviewed a proposed custom design system named "Acme" with four rules. A chat holds a deck of five slides.
- **When:** The user saves "Acme".
- **Then:**
  - "Acme" is among the custom design systems the user can choose.
  - Every slide of the deck is as it was.
  - No visual style changed.
- **Check:** deterministic

### AC-2 · A custom design system can start from another one

- **Given:** The custom design system "Acme" is saved with a heading font.
- **When:** The user starts from "Acme", changes the heading font, and saves the result as "Acme 2".
- **Then:**
  - "Acme" keeps its earlier heading font.
  - "Acme 2" holds the changed heading font.
- **Check:** deterministic

### AC-3 · A changed custom design system keeps its name

- **Given:** The custom design system "Acme" is saved with a brand colour. A deck was built with "Acme".
- **When:** The user changes the brand colour of "Acme" and saves under the same name.
- **Then:**
  - "Acme" shows the new brand colour.
  - Every slide of the deck is as it was.
  - No visual style changed.
- **Check:** deterministic

### AC-4 · A custom design system is created from a built-in one

- **Given:** The built-in design system "Corporate" holds a brand colour and a heading font. A deck of five slides was built with "Corporate".
- **When:** The user starts a custom design system from "Corporate", changes the heading font and saves it as "Report".
- **Then:**
  - "Report" holds the changed heading font.
  - "Report" is among the custom design systems the user can choose.
  - "Corporate" holds its original heading font.
  - Every slide of the deck is as it was.
- **Check:** deterministic

## Notes

- "Corporate" in AC-4 is a test fixture name. The built-in design systems the product offers are not set.
