---
id: FR-032
title: "Apply an unclear change to every slide"
---

## Requirement

- **Statement:** The user can choose to apply an unclear change to every slide. The system then replaces every existing slide with a new version made with the instruction. It builds each new slide the request asks for with the same instruction. It asks nothing more first.
- **Updated at:** 25-10-2026

## Acceptance conditions

### AC-1 · No further question, no slide lost

- **Given:** A deck of five slides. The user sent "make it more formal". The system offered its outcomes and waits for the answer.
- **When:** The user chooses to apply the change to every slide.
- **Then:**
  - The system asks nothing more before it changes the slides.
  - The deck has five slides.
  - No outline proposal appears.
- **Check:** deterministic

### AC-2 · Every slide follows the instruction

- **Given:** The state after AC-1.
- **When:** The system has changed the slides.
- **Then:**
  - The wording of each slide is more formal than before.
- **Check:** judged

### AC-3 · A tone change keeps what it does not ask to change

- **Given:** The state after AC-1. The instruction "make it more formal" asks only for a change of tone.
- **When:** The system has changed the slides.
- **Then:**
  - Each new version keeps the subject of the slide it replaces, at the same place.
  - Each new version keeps the facts of the slide it replaces.
- **Check:** judged
- **Why:** The use case replaces each slide with "a new version made with the instruction". It does not say what of a slide stays. Every slide being in the scope does not mean that every part of a slide changes. This default keeps the parts the instruction does not ask to change. An instruction that asks to change subjects or facts can still change them. Full deck regeneration is a separate workflow, not this one. Trade-off: the system does not improve unrequested parts of a slide while it applies the instruction.

### AC-4 · New slide uses the same instruction

- **Given:** A deck of five slides. The user sent "make it more formal and add a slide on costs". The user then chose to apply the change to every slide.
- **When:** The system has finished the request.
- **Then:**
  - The deck has a new slide on costs.
  - Its wording is as formal as the other slides.
- **Check:** judged
