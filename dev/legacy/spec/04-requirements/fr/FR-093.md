---
id: FR-093
title: "Choose a design system for a deck"
---

## Requirement

- **Statement:** The user can choose a built-in design system or a saved custom design system for a deck, and needs no custom design system to use a built-in one. The slides the system generates or changes then use the chosen design system. Choosing a design system changes no rule of it and saves no copy of it; when the user chooses none, the system uses the default design system [BR-003].
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · A chosen design system is used instead of the default

- **Given:** The default design system and a design system "Acme" are set up. A chat has no deck. The user prepared a request for a new deck and chose no design system yet.
- **When:** The user chooses "Acme" for the deck and the system builds the slides.
- **Then:**
  - The deck uses "Acme" rather than the default design system.
  - No slide uses a rule that only the default design system holds.
  - "Acme" and the default design system hold the same rules as before the request.
- **Check:** judged

### AC-2 · A chosen design system applies to a later design change

- **Given:** A deck of five slides was built with the default design system. "Acme" is set up.
- **When:** The user sends "use the Acme design system on slides 2 and 3".
- **Then:**
  - Slides 2 and 3 follow the rules of "Acme".
  - Slides 1, 4 and 5 are as they were before the request.
  - "Acme" holds the same rules as before the request.
- **Check:** judged

### AC-3 · Choosing a design system saves nothing new

- **Given:** "Acme" is set up with four rules. A chat has no deck.
- **When:** The user chooses "Acme" for a new deck and the system builds the slides.
- **Then:**
  - "Acme" still holds the same four rules.
  - The system saved no new design system.
- **Check:** deterministic

### AC-4 · Available design systems can be reviewed

- **Given:** DeckAgent provides built-in design systems. The user saved two custom design systems. The default design system is available.
- **When:** The user chooses to review available design systems.
- **Then:**
  - The system shows the available built-in design systems.
  - The system shows both custom design systems.
  - The system shows the default design system.
  - No design system is changed or selected for a deck by this action alone.
- **Check:** deterministic

### AC-5 · A built-in design system is chosen without a custom copy

- **Given:** DeckAgent provides a built-in design system that holds a brand colour and a heading font. A chat has no deck.
- **When:** The user chooses that built-in design system for a new deck and the system builds the slides.
- **Then:**
  - The slides follow the brand colour and the heading font of the built-in design system.
  - The built-in design system holds the same rules as before the request.
  - No custom design system is among the design systems the user can choose.
- **Check:** judged
