id: FR-033
title: "Apply an unclear change to new slides only"
---

## Requirement

- **Statement:** When the user chooses to apply an unclear change to new slides only, the system changes no existing slide. It builds each new slide the request asks for with the new instruction.
- **Updated at:** 25-10-2026

## Acceptance conditions

### AC-1 · Existing slides stay

- **Given:** A deck of five slides. The user sent "make it more formal and add a slide on costs". The system offered its outcomes and waits for the answer.
- **When:** The user chooses to apply the change to new slides only.
- **Then:**
  - Slides 1 to 5 are the same as before the request.
  - The deck has six slides.
- **Check:** deterministic

### AC-2 · New slide follows the instruction

- **Given:** The state after AC-1.
- **When:** The system has finished the request.
- **Then:**
  - The new slide is about costs.
  - Its wording is formal.
- **Check:** judged
