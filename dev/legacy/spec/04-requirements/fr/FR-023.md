id: FR-023
title: "Show the deck while the slides are built"
---

## Requirement

- **Statement:** While it builds the slides, the system shows the deck canvas and shows that work is in progress. It shows each slide once it is done, and which slides are done and which are still to come [NFR-004] [NFR-009] [NFR-013]. It does not change which slide the user is looking at. At the end, the deck canvas shows the full draft deck.
- **Updated at:** 26-10-2026

## Acceptance conditions

### AC-1 · Deck canvas shows that work started

- **Given:** The user confirmed an outline of four planned slides. No slide is done yet.
- **When:** The system starts to build the slides.
- **Then:**
  - The system shows the deck canvas.
  - The deck canvas shows that work is in progress.
  - The deck canvas shows that slides are still to come.
- **Check:** deterministic

### AC-2 · A finished slide shows before the others are done

- **Given:** The state of AC-1.
- **When:** The system finishes the first slide and still builds the others.
- **Then:**
  - The deck canvas shows the finished slide.
  - The deck canvas shows that more slides are still to come.
  - The system still shows that it works on the request.
- **Check:** deterministic

### AC-3 · The slide the user looks at stays the same

- **Given:** The deck canvas shows two finished slides. The user is looking at the first slide. The system still builds the others.
- **When:** The system finishes the third slide.
- **Then:**
  - The user is still looking at the first slide.
  - The deck canvas holds the third slide.
- **Check:** deterministic

### AC-4 · No slide added by hand meanwhile

- **Given:** The state of AC-2.
- **When:** The user looks for a way to add a slide by hand.
- **Then:**
  - The system offers no way to add a slide by hand.
  - The deck canvas holds the same slides as before.
- **Check:** deterministic

### AC-5 · Full draft deck at the end

- **Given:** The system builds the last slide of the draft.
- **When:** The system finishes it.
- **Then:**
  - The deck canvas shows every slide of the draft.
  - The deck canvas no longer shows that slides are still to come.
  - The deck canvas no longer shows that work is in progress.
- **Check:** deterministic

## Notes

- The status message while the system works is covered by FR-012. What each slide holds is covered by FR-022. FR-092 covers when the system can call a slide finished.
- A stop or a failure before the last slide is covered by FR-025 and FR-026.
