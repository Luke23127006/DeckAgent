---
id: FR-009
title: "Draft without a file that has nothing usable"
---

## Requirement

- **Statement:** The system uses nothing from an accepted file that has nothing usable, and claims no content from it. It names the file and the reason in the message with the outline. It drafts from the rest of the request and material.
- **Updated at:** 25-10-2026

## Acceptance conditions

### AC-1 · File is named

- **Given:** A chat with no deck. The request is "a talk on our pilot results, from these notes", with notes as text. It also has an attached document "appendix.pdf" that the system accepted. Every page of it is blank.
- **When:** The system shows the outline proposal.
- **Then:**
  - The message with the outline names "appendix.pdf".
- **Check:** deterministic

### AC-2 · Reason given, no content claimed

- **Given:** The state of AC-1.
- **When:** The system shows the outline proposal.
- **Then:**
  - The message says why the system did not use the document.
  - The system does not claim that it found usable content in the document.
  - No planned slide is presented as coming from the document.
- **Check:** judged

### AC-3 · Outline drafted from the rest

- **Given:** The state of AC-1.
- **When:** The system shows the outline proposal.
- **Then:**
  - The planned slides follow the request and the notes.
- **Check:** judged

## Notes

- A file that the system can use only in part is covered by FR-067.

- A file rejected when it is attached is not covered here. It never reaches the outline.
