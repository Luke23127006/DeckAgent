---
id: FR-063
title: "Delete a provider configuration"
---

## Requirement

- **Statement:** The user can delete a saved provider configuration that no active request uses. The system removes it and its added models from DeckAgent, and says so. It deletes and changes nothing at the provider. It keeps every other provider configuration, and every chat with its conversation and its deck. A chat whose selected model belonged to it has no selected model, and the system selects no other. A later provider configuration with the same provider ID is a new one. No chat takes its earlier selection again.
- **Updated at:** 25-10-2026

## Acceptance conditions

### AC-1 · The provider configuration and its models go

- **Given:** "Work AI" connects to provider P with the key K1 and has the added models M1 and M2. "Lab" is a custom model API with the provider ID "lab" and the added model M1. No request is active.
- **When:** The user deletes "Work AI".
- **Then:**
  - The model setup shows "Lab" as saved, and no "Work AI".
  - The user cannot choose M1 or M2 of "Work AI" for any chat.
  - The user can still choose M1 of "Lab".
- **Check:** deterministic

### AC-2 · Nothing changes at the provider

- **Given:** The state of AC-1, before the user deletes "Work AI". A test account with P records each request it receives.
- **When:** The user deletes "Work AI".
- **Then:**
  - P receives no request.
- **Check:** deterministic

### AC-3 · Chats and decks stay

- **Given:** The state of AC-1, before the user deletes "Work AI". Chat X has M1 of "Work AI" as its selected model. It has a conversation of four messages and a deck of five slides.
- **When:** The user deletes "Work AI" and opens chat X.
- **Then:**
  - The conversation of chat X shows the same four messages.
  - The five slides of chat X are the same as before.
  - Chat X has no selected model. M1 of "Lab" is not its selected model.
- **Check:** deterministic

### AC-4 · Adding the provider again starts a new provider configuration

- **Given:** The state after AC-3.
- **When:** The user adds a provider configuration for P with the key K3 and the display name "Work AI". The user adds the model M1 to it, and opens chat X.
- **Then:**
  - The model setup shows "Work AI" with provider P as saved.
  - Chat X still has no selected model. M1 of the new "Work AI" is not its selected model.
- **Check:** deterministic

### AC-5 · The user is told

- **Given:** The state of AC-1, before the user deletes "Work AI".
- **When:** The user deletes "Work AI" and reads the response.
- **Then:**
  - The response says that "Work AI" was deleted.
- **Check:** judged

## Notes

- A provider configuration that an active request uses is covered by FR-064. A request in a chat whose selected model was deleted is covered by FR-056. The selected model of a new chat is covered by FR-053.
- Removing one added model is covered by FR-059.
