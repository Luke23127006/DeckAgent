# DeckAgent presentation Skill for OpenCode

Requires Node 22.19 or later within the repository's supported range, pnpm 11.28.5,
a built DeckAgent checkout and an installed OpenCode 1.19.5 executable.
Only native Gemini is configured by the convenience launcher. Set GEMINI_API_KEY in the environment or optional .env.
Never put the key in commands, Skill files or evidence.

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd build
```

Use an absolute path to a new dedicated profile, not an active Web profile.
Replace all placeholders below. The launcher starts OpenCode directly, without DeckAgent Web or an AgentRuntime.
It installs only this Skill into an isolated configuration directory for each execution.
No global OpenCode settings are changed. Source project files are never available as writable tools.

```powershell
pnpm.cmd presentation:skill --profile "D:\DeckAgent-Skill-Test" --session demo --version 0 --opencode "<absolute path to opencode.exe>" --prompt "Use deckagent-presentation. Propose two Vietnamese slides about recycling and wait for operator confirmation."
pnpm.cmd presentation:tools --profile "D:\DeckAgent-Skill-Test" --session demo --action inspect
```

Read the saved overview/content before confirming. Copy the current outline ID and its version from inspect.
Confirmation prints the stable slide IDs and deck version.

```powershell
pnpm.cmd presentation:tools --profile "D:\DeckAgent-Skill-Test" --session demo --action confirm --outline "<outline ID>" --version "<outline version>"
pnpm.cmd presentation:skill --profile "D:\DeckAgent-Skill-Test" --session demo --version 1 --slides "<slide ID 1>,<slide ID 2>" --opencode "<absolute path to opencode.exe>" --prompt "Use deckagent-presentation. Read presentation_state and publish both confirmed slides now."
```

Inspect again. Supply the current deck version and only the slide IDs the user wants to edit.

```powershell
pnpm.cmd presentation:tools --profile "D:\DeckAgent-Skill-Test" --session demo --action inspect
pnpm.cmd presentation:skill --profile "D:\DeckAgent-Skill-Test" --session demo --version "<current deck version>" --slides "<slide ID 2>" --opencode "<absolute path to opencode.exe>" --prompt "Use deckagent-presentation. Edit the authorized slide heading to TEST_SKILL_8 through read_slide and patch_slide. Keep other content unchanged."
```

Stop with Ctrl+C. Inspect saved revisions before retrying; completed saves remain committed.
Every launch uses a fresh native session and explicit grants. There is no automatic continuation or retry.
Decks and outlines persist in the selected profile; Web chat history is not generated by this workflow.

## External contract 1

The MCP command is `node <checkout>/apps/local-web/lib/external-cli.js --action serve --profile <absolute profile> --session <ID> --version <deck version> --slides <comma-separated stable IDs>`.
stdio is the transport; stdout carries MCP only. It requires an operator-controlled host that denies native bypass tools.
Do not point a general unrestricted agent at a private profile and claim equivalent isolation.

presentation_state reports contractVersion, outline, deck and authorizedSlideIds.
Before confirmation, propose_outline is available; publication tools are absent.
After operator confirmation and explicit scope, publish_slide and patch_slide are available.
read_slide returns revision-bound editor nodes/baseHash. All inputs are closed objects; serialized inner JSON is validated by DeckService.
There is no confirm tool, arbitrary file path, model-selected session ID or network tool.

The bounded external contract does not expose attachments, image acquisition, PDF export or Web workflow admission.
Never use it concurrently with the Web app on the same Chat. Use a separate dedicated profile.

OpenCode Skill placement and MCP configuration follow the official documentation:
[Skills](https://opencode.ai/docs/skills/) and [MCP servers](https://opencode.ai/docs/mcp-servers/).
The installed pinned executable is the qualification authority when newer documentation differs.
